{{ passives(['empyrean-lords-grace', 'earths-grace', 'healing-enhancement', 'radiant-benediction']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

AION 2のダンジョンでは、クレリックは火力も出さなければならないヒーラーだ。報酬は貢献度で決まるため、回復しかしないクレリックは何ももらえずに終わることもある。パーティー メンバーは自前の回避や無敵を十分に持っている。被弾した人だけを回復し、それ以外はすべて火力に回そう。

ビルドを一言で

{{ s('earth-punishment') }}で{{ s('condemnation') }}が必ずクリティカルになり、クリティカルで断罪の再使用時間が初期化される。つまり断罪はクールタイムなしで撃ち続けられ、そこに{{ s('divine-aura') }}、{{ s('bolt') }}、{{ s('noble-aura') }}の火力が上乗せされる。

このモードはKaeriaのクレリックPvE動画ガイド（ロシア語。9月28日に台湾版クライアントで収録され、本人はグローバル版にも当てはまると話している）に基づき、9月30日に動画のフレームと照合した。スキルの特化はいつでも無料で振り直せる。資源を消費するのはアルカナだけだ。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版のサーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。クレリックにとっての変更点は次のとおり。

  • スティグマ枠は4つ、上限は20。Kaeriaの台湾版のバーにはもっと多く並んでいるが、このガイドの4つは本人がグローバル版向けに選んだもの。スティグマLv25の効果（保護の光の強打など）はグローバル版には存在しない。
  • 報酬は火力で決まる。ダンジョンの報酬は貢献度次第なので、回復しかしないクレリックは何ももらえずに終わることもある。このビルドは、回復を片手間にこなしながら火力を出すことに徹している。
  • 大人数のパーティー（5人の遠征、10人の聖域）：チャンターがいると、こちらのマントラはチャンターのマントラと重複しない。その場合は保護の光を外そう。
  • 台湾版よりPingが低い：モーションキャンセルが効きやすくなり、マクロに通常攻撃を多めに挟める。

アクティブスキルとパッシブは、グローバル版とKR/TWのデータで同一。スティグマはLv25の効果がなくなる。元の動画は、スキル名が英語表示の台湾版クライアントで収録されている。

ディーヴァニオンはスキルを10から14まで引き上げ、ステータスも追加する。青いノードはそれぞれ、対応するスキルをLv+1する。

  • 優先度：まずオレンジの再使用時間と戦闘速度のノード、次に攻撃力とクリティカル、次に青いスキルノード、次に防御系のオレンジノード、パッシブは最後。
  • クリティカル ダメージ耐性と多段ヒット抵抗はPvEでは役に立たない。ボスはクリティカルも多段ヒットも出さない。
  • ボードのリセットは安く、何度も組み直すことになる。
  • グローバル版にアリエルはない：ボードは5枚で、Lv45のアスフェルはPvPダメージ増幅と耐性しか付かない。PvEでは最初の4枚を完成させよう。

    {% call skill('earth-punishment', 'must', 'Lv15 → 20', upto=20) %}断罪が必ずクリティカルになり（つまり断罪の再使用時間がなくなる）、パーティーは防御力、攻撃力、強打を得る。最も重要なスキルの一つ。{% endcall %} {% call skill('light-of-protection', 'must', 'Lv20', upto=20) %}自分のマントラ。受ける治癒量、命中、最大HP+10%、完璧が上がり、再使用時間はない。チャンターのマントラとは重複しないので、チャンターがいるパーティーでは外す。切り替え式のスキルなので、一度オンにしたらホットバーのラインにもマクロにも入れないこと。{% endcall %} {% call skill('prayer-of-amplification', 'must', 'Lv10+', upto=10) %}クールタイムごとに使って攻撃力+20%。神の恩恵と大地の恩恵の効果も強化する。これがないとクレリックは火力が出ない。{% endcall %} {% call skill('noble-aura', 'must', 'Lv10+', upto=10) %}一緒に攻撃してくれる気の玉。火力がおよそ倍になる。レベルは高いほどよい。{% endcall %} {% call skill('absolution', 'opt', '聖域', upto=15) %}最強の回復スティグマだが、強いのは15以上から。パーティーの回復が足りないときだけ入れ替える。{% endcall %} {% call skill('benevolence', 'opt', '聖域', upto=15) %}パーティー全体への持続回復。免罪と同じく、枠を割く価値が出るのは15から。{% endcall %} {% call skill('yustiels-power', 'opt', '聖域', upto=15) %}10秒間、パーティーのダメージ耐性を上げる。聖域で高潔な気か増幅の祈りの代わりに入れる。{% endcall %} {% call skill('summon-resurrection', 'opt', 'Lv5', upto=5) %}序盤は5で止めておく。パーティーがよく死ぬなら入れる。{% endcall %} {% call skill('salvation', 'skip', '不要') %}長い再使用時間に対して無敵は3秒。赤い攻撃はどのみち貫通するので、回避で対処しよう。{% endcall %}

チャンターがいるパーティーでは、保護の光を回復スティグマのどれかか召喚復活に替える。破滅の声（15でボスのクリティカル抵抗−200）は、ヒーラーがもう一人いる聖域での選択肢。主に、全員のクリティカルが足りない序盤向け。権能爆発は、グロッキー ゲージを削り切る必要があり、ほかに削れる人がいない場面（悪夢）でのみ使う。{{ s('root') }}と{{ s('assault-mark') }}はPvEでは使い道がない。

Kaeriaはゲーム内マクロだけを使い、外部ツールは使わない。そのため、マクロの合間にも回復を押せる。以下のラインは、動画に映った彼女のホットバーから読み取ったもの。AION 2ではラインの一番下のスロットが最優先になる。カードは各ラインを、ゲーム内と同じく上から下へ表示している。

1. ホットバーのライン

{% call hotline('3', '断罪ライン', ['earth-punishment', 'condemnation', 'chain-of-torment']) %}大地の懲罰を最初に置くことで、断罪が必ずクリティカルになり再使用時間が初期化される。苦痛の連鎖は、断罪に必要な烙印を維持する。{{ s('light-of-protection') }}はラインに入れない。切り替え式なので、押すたびにオンとオフが入れ替わってしまう。{% endcall %} {% call hotline('2', '神聖な気ライン', ['divine-aura', 'debilitating-mark', 'light-of-regeneration', 'judgment-thunder']) %}気とデバフは使えるようになり次第発動し、残りは審判の雷で埋める。{% endcall %} {% call hotline('1', 'グロッキー', ['lightning-strike-scattershot']) %}グロッキー状態のボスにしか効かないので、ほとんどの時間このステップは飛ばされる。{% endcall %}

3. キー操作

  • 長押し右クリックのマクロと3（断罪ライン）を同時に押し続ける。断罪は再使用時間がなく、ほかのすべてのスキルのモーションをキャンセルする。
  • グロッキーボスがグロッキーになったら3を離してマクロだけを押し続け、{{ s('lightning-strike-scattershot') }}が発動するようにする。
  • 手動誰かが被弾した直後に{{ s('healing-light') }}（彼女は4に配置）と{{ s('radiant-recovery') }}（Q）、フルチャージの{{ s('bolt') }}（E）、{{ s('prayer-of-amplification') }}はクールタイムごとに。

これは高Ping向けに組まれた、彼女の台湾版での設定。Pingの低いグローバル版ではモーションキャンセルが効きやすく、大地の裁きをもう少し多く挟める。

クレリックはヒーラーだが、レベリング中は遠距離アタッカーとして戦う。{{ s('chain-of-torment') }}で対象に印を付け、{{ s('condemnation') }}で叩き、パッシブの{{ s('radiant-benediction') }}が攻撃のたびに自分とパーティーを回復する。回復は必要なときだけでよい。

レベリングを一言で

MP回復のために{{ s('earths-retribution') }}を押し続け、ゲーム内マクロで連鎖ラインを連打する。スキルポイントは回復ではなく攻撃スキルに振る。

{% endcall %} {% call section('fight-lvl', t.lvl_combat, 'lvl') %}
  • 集団：{{ s('chain-of-torment') }}（最大4体に命中）→ {{ s('condemnation') }} → 広域化した{{ s('divine-aura') }} → {{ s('judgment-thunder') }}。
  • エリート：{{ s('debilitating-mark') }}（防御力低下）→ {{ s('chain-of-torment') }} → チャージした{{ s('bolt') }} → {{ s('condemnation') }}。
  • MP：ターゲットモードにして、{{ s('earths-retribution') }}を挟む。使うたびにMPが回復する。
  • HPが少ないとき：{{ s('healing-light') }}。攻撃を続けている限り、{{ s('radiant-benediction') }}の回復も入り続ける。
  • グロッキー中のボス：{{ s('lightning-strike-scattershot') }}は対象がグロッキー状態のときしか使えない。

{{ passives(['empyrean-lords-grace', 'healing-enhancement', 'earths-grace', 'survival-willpower']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

AION 2のダンジョンでは、クレリックは火力も出さなければならないヒーラーだ。報酬は貢献度で決まるため、回復しかしないクレリックは何ももらえずに終わることもある。パーティー メンバーは自前の回避や無敵を十分に持っている。被弾した人だけを回復し、それ以外はすべて火力に回そう。

ビルドを一言で

{{ s('earth-punishment') }}で{{ s('condemnation') }}が必ずクリティカルになり、クリティカルで断罪の再使用時間が初期化される。つまり断罪はクールタイムなしで撃ち続けられ、そこに{{ s('divine-aura') }}、{{ s('bolt') }}、{{ s('noble-aura') }}の火力が上乗せされる。

このモードはKaeriaのクレリックPvE動画ガイド（ロシア語。9月28日に台湾版クライアントで収録され、本人はグローバル版にも当てはまると話している）に基づき、9月30日に動画のフレームと照合した。さらにLuciaのガイド（英語、グローバル版、10月5日。アイテムレベル2,160で世界初のランク1になったクレリック）とも照合している。スキルの特化はいつでも無料で振り直せる。資源を消費するのはアルカナだけだ。

{% endcall %} {% call section('intro-pvp', '概要', 'pvp') %}

PvPでもPvEの軸は変わらない。クリティカルで再使用時間が初期化される{{ s('condemnation') }}、{{ s('judgment-thunder') }}、回復スキルだ。変わるのはスティグマといくつかの特化の役割で、CC、敵の回復の阻害、バーストを受けたパーティーを生き残らせることに向ける。

ビルドを一言で

{{ s('prayer-of-amplification') }}と{{ s('light-of-protection') }}でバフをかけ、倒しにいくヒーラーかタンクに{{ s('voice-of-doom') }}を入れ、{{ s('yustiels-power') }}は敵がバーストを仕掛ける瞬間まで取っておく。

このモードはLuciaのクレリック ガイド（英語、グローバル版、10月5日。世界初のランク1クレリック）のPvPパートに基づく。決闘とパーティー戦のスティグマ、PvP向けに変える特化を扱う。PvPのコンボは別の動画で解説すると本人が予告しており、それまではローテーションはPvEと同じ。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版のサーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。クレリックにとっての変更点は次のとおり。

  • スティグマ枠は4つ、上限は20。Kaeriaの台湾版のバーにはもっと多く並んでいるが、このガイドの4つは本人がグローバル版向けに選んだもの。スティグマLv25の効果（保護の光の強打など）はグローバル版には存在しない。
  • 報酬は火力で決まる。ダンジョンの報酬は貢献度次第なので、回復しかしないクレリックは何ももらえずに終わることもある。このビルドは、回復を片手間にこなしながら火力を出すことに徹している。
  • 大人数のパーティー（5人の遠征、10人の聖域）：チャンターがいると、こちらのマントラはチャンターのマントラと重複しない。その場合は保護の光を外そう。
  • 台湾版よりPingが低い：モーションキャンセルが効きやすくなり、マクロに通常攻撃を多めに挟める。

アクティブスキルとパッシブは、グローバル版とKR/TWのデータで同一。スティグマはLv25の効果がなくなる。元の動画は、スキル名が英語表示の台湾版クライアントで収録されている。

  • グローバル版にアリエルはない：ボードは5枚で、Lv45のアスフェルはPvPダメージ増幅と耐性しか付かない。PvEでは最初の4枚を完成させよう。

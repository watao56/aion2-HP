{{ passives(['fury', 'punishing-benediction', 'ironclad-defense', 'survival-willpower']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

テンプラーはAION 2のメインタンクで、それでいて火力もしっかり出る。ビルド全体を支えるのは、できるだけ早く20まで上げる3つのスキルの「三位一体」：{{ s('judgment') }}、{{ s('punishment') }}、{{ s('pummel') }}。これをとにかく回せるだけ回す。テンプラーの限界を決めるのは生存力ではなく火力だ。

ビルドを一言で

盾スキルが{{ s('judgment') }}を発動させる。審判ラインをサイドボタンで連打し、マクロを押しっぱなしにして連続乱打とその発動スキルを回す。{{ s('punishment') }}は再使用時間が明けるたびにチャージして撃ち、大きな攻撃はガードしてパーティーに{{ s('fury') }}を維持する。

このガイドはSolAshurのグローバル版ローンチ向けテンプラービルド（solashur.com、9月27日）と、その解説動画（9月29日）に基づく。9月30日に動画のフレームと照らし合わせて再確認した。

{% endcall %} {% call section('intro-pvp', '概要', 'pvp') %}

PvPでも三位一体と審判のループは変わらない。変わるのはスティグマだ。{{ s('executing-blade') }}はどの決闘でも優位をもたらし、{{ s('annihilate') }}は20で範囲転倒スキルになる。

近接はカイトされる。相手に届かなければ強い武器も意味が薄いので、接近スキルと破滅のシールドを軸に立ち回ろう。

KR/TWのPvP専用装備セットはグローバル版での実装が未確認なので、PvEタブのPvX装備で進める想定だ。PvP装備が出た場合は、まずPvPスティグマを上げ、そのあとでPvP武器や防具に投資する。

初日から始めるなら、ルートは次のとおり。

  1. 聖霊セット：アビス下層（1体倒すごとにアビス ポイント、ペット、ゴールドがドロップし、ボスも出現する）か、オープンワールドのどこでも集められる。戦闘力1,600前後が目安。
  2. 最初のダンジョン帯は飛ばす：ウルググ峡谷でアウルラムスのロングソード（アイテムレベル76、攻撃力308–385、取得時に刻印）、バクロンの空中島でバクロンのガーダー（アイテムレベル76）とバクロンの防具を狙う。炎の神殿に挑めるようになるまでバクロン装備を強化し続ける。
  3. 超越で炎の神殿（怒りのクロメデのソード：アイテムレベル84、攻撃力340–425、射程延長）と獰猛な角岩窟（Nuakum防具）に備える。周回はNuakumの方が安全：ほぼ全部位が更新になる一方、武器箱からは他クラスの武器が出ることがある。
  4. 最終目標：PvEなら白龍王の剣、次に盾、次にアクセサリーで、防具はNuakum（白龍防具一式はPvE耐性が増えるだけで、重課金者の領域）。大半のプレイヤー向けのPvX構成は、怒りのクロメデの剣、白龍の盾、Nuakum防具、白龍のアクセサリー。

翼：序盤はDark Veil（追加攻撃力、ダメージ増幅）、終盤はTalisra：攻撃力60、防御力400、命中35、再使用時間減少4%。再使用時間減少はできるだけ早く積もう。盾スキルのクールタイムが短いほど審判の発動が増える。ほかの翼もすべて集めておく。「所持」効果と飛行力がアビス周回の助けになる。

AION 2には別々のツールが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと使用可能なスキルのうち最も優先度の高いものが発動し、AION 2では一番下のスロットが最優先になる。カードは各ラインをゲーム内と同じく上から下の順に表示している。
  • ゲーム内マクロ：キーを押している間、ホットバーラインを順番に押し、モーションの後隙をキャンセルする。再使用待ちのスキルは飛ばされる。

1. ホットバーライン

{% call hotline('右クリック', '連続乱打ライン', ['annihilate', 'debilitating-smash', 'flash-rampage', 'pummel']) %}ゲーム内マクロが押すのはこのライン。発動スキルは光った瞬間に発動し、それ以外は連続乱打が埋める。{{ s('flash-rampage') }}はグロッキー状態の対象にしか当たらない。それ以外のときはマクロが飛ばし、グロッキー中は1ヒットごとに全スキルの再使用時間が1s短くなる。{% endcall %} {% call hotline('サイド', '審判ライン', ['judgment', 'shield-smite', 'warding-strike', 'doom-shield']) %}連打する。盾スキルはすべて審判を発動させ、審判が常に優先される。{% endcall %} {% call hotline('右クリック · PvX', 'PvX用の連続乱打ライン', ['doom-shield', 'annihilate', 'debilitating-smash', 'pummel']) %}PvXプリセットでの同じボタン。{{ s('flash-rampage') }}が抜け、{{ s('doom-shield') }}が最優先になり、残りは順に下がる。審判ラインにも入れているのは意図的だ。ここでは戦闘の開幕役で、突進してNPCに確定転倒を入れ、{{ s('annihilate') }}を使えるようにする。さらにLv15では敵を倒すと再使用時間が初期化され、PvXとペット周回の要になる。{% endcall %}

  • 左クリック{{ s('vicious-strike') }}（クイックスロット1）。
  • 右クリックゲーム内マクロ（連続乱打ライン）、10ms。
  • サイドボタン審判ライン。SolAshurはRに割り当て、マウスでRを毎秒約10回リピートさせている。
  • 手動チャージした{{ s('punishment') }}を再使用時間ごとに、{{ s('battlefield-banner') }}、グロッキー用の{{ s('empyrean-lords-punishment') }}、{{ s('taunt') }}。

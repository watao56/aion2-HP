{{ passives(['rear-smite', 'exploit-weakness', 'assault-stance', 'determination']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

アサシンはバフ頼みのダガー系バーストクラス。攻撃を当てると対象に紋様が刻まれ、{{ s('insignia-explosion') }}でそれを一気に爆発させる。{{ s('heart-gore') }}はクリティカルで発動し、次のクリティカルで自分の再使用時間がリセットされる。最大のダメージボーナスは対象の背後から当てることで得られるため、立ち位置の重要度はどのクラスよりも高い。

ビルドを一言でまとめると

ボスの背後に立ち、{{ s('quick-slice') }}を常に挟み、{{ s('insignia-explosion') }}は使えるようになった瞬間に、{{ s('heart-gore') }}はクリティカルのたびに押す。そして心臓突きの再使用時間が完全になくなる{{ s('illusive-clone') }}の20秒間に、持てる火力をすべて注ぎ込む。

シーズン1で覚悟しておくこと

  • バーストの後に空白がある。KR/TWでは幻影分身のLv25段階のおかげで、上手いプレイヤーは常時維持できる。グローバル版は20止まりなので、再使用時間1分30秒に対してバーストは約20秒。その合間はつなぎ技で戦い、心臓突きはクリティカルの運任せになる。
  • バフの周期が揃わない。迅速の契約と猛獣の牙は1分、幻影分身は1分30秒で戻ってくる。待つか押すかを常に判断し続けることになる。
  • 背後を取れている時間がそのまま火力。木人相手なら100%だが、実戦では60〜80%と見ておこう。正面から当てた攻撃はすべて背後強打のボーナスを失う。
  • 打たれ弱い。ガードがなく防御力も低い。グラディエーターなら耐えられるミスでも死ぬ。

Arthars の評価：楽しくて腕前が問われるクラスだが、グラディエーターやソーサラーと同じかそれ以下のダメージを出すのに何倍もの手間がかかる。数字目当てではなく、プレイスタイルが好きで選ぶクラスだ。

PvEモードは、Arthars Gaming のグローバル版ローンチ向けアサシン動画(9月30日、台湾サーバーで収録)を1フレームずつ読み取ってまとめた。動画に字幕がないため、テキストは音声認識で音声から起こし、名前と数値はすべて画面と照合している。レベリングは TitanTheF のシートに基づく。

グローバル版サーバーは2026年10月5日にオープンする(ファウンダー先行アクセスは9月30日から)。アサシンにとっての影響は次のとおり。

  • スティグマ枠は4つ、上限は20。4つともダメージ用に使う：幻影分身、迅速の契約、猛獣の牙、トリニエルの刃。
  • 幻影分身の常時維持はできない。背後クリティカルで再使用時間が短縮される段階はLv25で、グローバル版にはない。
  • 序盤は再使用時間減少が少ない。暴風乱舞を16まで上げ、トリニエルの刃をダメージ目的ではなく再使用時間短縮の道具として使うのはこのため。
  • 戦闘が長引く。台湾サーバーで30秒で倒れるボスも数分かかるはず。バーストのタイミングもその合間も何度も経験することになる。
  • PvP：全員が同じ限られた装備からのスタートで、メタはまだ固まっていない。

アクティブスキルとパッシブはグローバル版とKR/TWのデータで同一。スティグマはLv25段階がなくなる。

厳選の本番は羊皮紙。20にしたい3スキルがすべてこの1枚に載っているのに、シーズン1のカードは4行のうち2行しか選べない。カードのレベルを上げるとランダムに+1が4回付く。1つに+4が偏るより、均等に散る(それぞれ+2)ほうがありがたい：足りない+2は聖杯で補える。うまくいかなければ、心臓突きと紋様爆発を20にして迅速斬りは16のままにする。

コンパスと鐘は気楽でいい：どちらも20にする必要のあるスキルはない。これらのカードはどれも、シーズン2で新カードが来たら入れ替わる。

4枠すべてバフ。まず幻影分身を20にする(スティグマ シャードの大半はこれに消える)。残りはその後。

    {% call skill('illusive-clone', 'must', 'Lv20', upto=20) %}バーストの要。20秒間、心臓突きの再使用時間がなくなり、与ダメージが20%増える。さらにクリティカル ダメージ+20%と隙突き×1.5も乗る。再使用時間は1分30秒。ダメージの大半はこの中で出るので、雑魚には使わずボスに使う。aLuckyRO によると、心臓突きが16になるまでは必須。クリティカルが十分あれば心臓突きは勝手にリセットされるので、しばらくは枠を入れ替えてもいい。ただし20になったら、ダメージ増加目当てで戻ってくる。{% endcall %} {% call skill('swift-contract', 'must', 'Lv15 → 20', upto=15) %}持続中は戦闘速度+20%、背後強打と強襲姿勢の効果×1.5。最初は15で十分。20で戦闘速度がさらに10%増える。{% endcall %} {% call skill('savage-fang', 'must', 'Lv15', upto=15) %}紋様を一度に5個刻み、グロッキー ダメージも大きい。15では10秒間PvEダメージ増幅+10%。迅速の契約と同じ1分の再使用時間なので、一緒に押そう。{% endcall %} {% call skill('triniels-dagger', 'must', 'Lv10', upto=10) %}ダメージ目的ではない：10では、当てるとすべてのスキルの残り再使用時間が10%短くなる。再使用時間が最も長い、バフを使った直後に押そう。{% endcall %} {% call skill('evasion-stance', 'opt', 'Lv5–10', upto=10) %}大技を確実に回避できる。5で2回使えるようになり、10で移動しながら使える。打たれ弱いクラスなので、戦闘を覚えるまではバフの1つと入れ替える安全策になる。{% endcall %} {% call skill('throw-shadowblade', 'opt', '周回', upto=10) %}20mの投擲で、10では敵を倒すと再使用時間がリセットされる。オープンワールドの周回向けで、ボス用ではない。{% endcall %}
{% endcall %} {% call section('macro', 'マクロとローテーション', 'pve') %}

AION 2には別々の仕組みが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと、使える中で優先度が最も高いスキルが発動する。AION 2では一番下のスロットが最優先。カードはゲーム内と同じく各ラインを上から下へ並べている。
  • ゲーム内マクロ：キーを押している間、ホットバーのボタンを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーライン

{% call hotline('E', 'ダメージライン', ['insignia-explosion', 'heart-gore', 'ambush', 'savage-roar']) %}紋様爆発は使えるようになるたびに、心臓突きはクリティカルのたびに発動する。どちらも使えなければラインはつなぎ技に落ちる：最初に奇襲、最後に猛獣の咆哮。{% endcall %} {% call hotline('7', 'バフライン', ['illusive-clone', 'swift-contract', 'savage-fang', 'triniels-dagger']) %}Arthars は4つのスティグマをすべて1つのボタンにまとめ、手動で押している。マクロからは絶対に押さない。バフの発動がずれてしまうからだ。{% endcall %}

2. ゲーム内マクロ

2ステップ、それぞれ10ms。押しっぱなしにできるキーに割り当てる。

{{ macroseq([('ダメージライン', '10ms'), (skill_data('quick-slice')[lang].name, '10ms')]) }}

動画ではホットバーは映っているが、マクロ画面は映っていない。このマクロは Arthars のチャンターガイドの設定(メインライン、次に基本攻撃)にならったもの。ラインとキーは彼のホットバーから読み取った。

3. 実際に押すもの

  • 押しっぱなしマクロキー。さらに{{ s('quick-slice') }}を自分で連打する。1ヒットごとに紋様爆発の再使用時間が短くなる。
  • バースト{{ s('illusive-clone') }}+{{ s('swift-contract') }}+{{ s('savage-fang') }}を同時に使い、すぐに{{ s('triniels-dagger') }}でそれらの再使用時間を削る。その後の20秒間は心臓突きを撃ち続ける。
  • バーストの合間迅速の契約と猛獣の牙は幻影分身より先に戻ってくる。次の分身まで温存する(バーストが大きくなる)か、クールタイムごとに使う(ダメージが安定する)か。決まった答えはないが、短い戦闘なら温存しよう。
  • グロッキーグロッキー中のボスに{{ s('storm-rampage') }}、合間に迅速斬りを挟む。すべての再使用時間が秒単位で縮む。
  • 位置取り{{ s('shadowstrike') }}、{{ s('flash-slice') }}、{{ s('infiltrate') }}はどれも対象の背後に回り込める。ダメージ用ではなく、背後に居続けるために使う。

Arthars の木人でのテストにおけるダメージ内訳：心臓突きが約30%、紋様爆発が約25%、それ以外はどれも6%以下。

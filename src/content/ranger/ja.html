{{ passives(['focused-eye', 'hunters-resolve', 'hunters-soul', 'concentrated-fire']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

レンジャーはボウで戦うDPSで、ほぼすべてのスキルの射程である約20mの距離から攻撃する。火力はトップクラスだが、生存力と補助性能は低いので、立ち位置がすべてを左右する。

ビルドを一言で

バフをかけ、対象に{{ s('marking-shot') }}（精密：クリティカル+300、{{ s('deadshot', False) }}のダメージ+35%）を維持したら、あとは{{ s('snipe') }}、マクロ、チャージした{{ s('deadshot') }}の3ボタンを押し続ける。

このガイドは、Whelps（韓国サーバーでCP 1Mのレンジャーメイン。グローバル版のテストもプレイ）がquestlogで公開しているシーズン1エンドゲームのPvEビルドに沿っている。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版サーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。レンジャーへの影響は次のとおり。

  • Lv37の時点でスティグマは4つ。グローバル版のテストはLv37までだった。Lv45で5枠目が開く可能性は高いが未確認。開いたら{{ s('explosive-arrow') }}を入れる。
  • 20に届くスキルはごく一部。スキルポイントで上げられるのは10まで。ディーヴァニオンで+4、リングで+2、アルカナで最大+4が乗る。シーズン1では必中の矢と狂風の矢を20にする前提で考え、アルカナの引きがよければ3つ目も20にする。
  • 命中の上限は不明。韓国ではルドラ向けで約1,300だった。グローバル版の数値はリリース後に判明する。
  • PvP：全員が同じ限られた装備からのスタートで、メタはまだ固まっていない。
{% endcall %} {% call section('skills', 'スキル', 'pve') %}

特化スロットは8、12、20で開く（16では新しいオプションが増えるだけで、スロットは増えない）。どのレベルも大きな強化ポイントになる。アクティブスキルを先に上げ、パッシブは後回し。

    {% call skill('deadshot', 'must', '20', [1, 2, 4]) %}チャージ型の大技。常にフルチャージで、常に精密状態で撃つ。20未満なら最初の2つを取る。チャージ中に動く必要がなければ、移動可能スキルの代わりに+50%ダメージの特化を取る。{% endcall %} {% call skill('gale-arrow', 'must', '20', [2, 3, 4]) %}戦闘速度とダメージのバフ。20未満なら移動可能スキルと再使用時間10秒減少を取る（移動の代わりにダメージ系でもよい）。{% endcall %} {% call skill('drill-dart', 'must', '16', [4, 2]) %}最低でも16。耐久が必要なボスでは、スキル速度の代わりにHP吸収を取る。{% endcall %} {% call skill('snipe', 'must', '16', [3, 4]) %}基本攻撃。必中の矢の再使用時間を縮め、連続スキルの疾風の矢を追加する。20では多段ヒットも足す。{% endcall %} {% call skill('tempest-shot', 'must', '16', [2, 4]) %}ダメージへの貢献はトップクラスだが、16で十分。どのみちクリティカルは上限に達する。PvPではノックバック目当てに20まで上げる人もいる。{% endcall %} {% call skill('snare-shot', 'opt', '12', [1, 2]) %}12まではディーヴァニオン ボードでほぼタダで届く。{% endcall %} {% call skill('marking-shot', 'opt', '12', [0, 2]) %}完璧+5%、持続時間+5秒。{% endcall %} {% call skill('burst-arrow', 'opt', '12', [2, 3]) %}20では最後の特化も取る。{% endcall %} {% call skill('explosion-trap', 'opt', '12', [0, 2]) %}雑魚をまとめるときだけ使う（超越の周回など）。{% endcall %} {% call skill('suppressing-arrow', 'opt', '12', [0, 2]) %}気絶目当てでのみ使う。レベリング中は便利だが、エンドゲームのPvEでは使わない。{% endcall %} {% call skill('defiance', 'opt', '12', [2, 1]) %}16では3番目と5番目の特化。{% endcall %} {% call skill('arrow-scattershot', 'opt', '序盤12', [2, 3]) %}グロッキー状態のボスにしか使えない。Whelpsは上げていない。彼のエンドゲームのローテーションでは、ほかのスキルのほうがダメージが出るからだ。aLuckyROとLordRobsonは初日に12まで上げ、グロッキー中の多段ヒットを狙っている。ポイントが安いうちはそれでいいが、後で真っ先に外すスキルになる。{% endcall %}

本当に重要なのは{{ s('focused-eye') }}（ダメージ増加）と{{ s('hunters-resolve') }}（クリティカル ダメージ）だけ。3番目が{{ s('hunters-soul') }}。

  • 次に攻撃系：{{ s('concentrated-fire') }}、{{ s('rooting-eye') }}、{{ s('melee-fire') }}。
  • その次に{{ s('vigilant-eye') }}（最大HP）と{{ s('revitalization-contract') }}（HP10%で回復）。
  • {{ s('unyielding-resolve') }}と{{ s('wind-vigor') }}はほぼ役に立たない。余ったポイントで上げる。

いずれはほぼすべてのボードを埋めることになるので、細かく計画しすぎなくていい。青いノードはどれも、対応するスキルをスキルLv+1する。

  • 1. アクティブスキルを12に上げる青ノード（2つ目の特化が開く）：{{ s('deadshot') }}、{{ s('snipe') }}、{{ s('gale-arrow') }}、{{ s('drill-dart') }}、{{ s('burst-arrow') }}。
  • 2. ボードの角にある攻撃系のオレンジノード（戦闘速度、再使用時間減少）。最短ルートで向かい、途中にあるスキルも拾っていく。
  • 3. 攻撃力、クリティカル、{{ s('focused-eye') }}、{{ s('hunters-resolve') }}のノード。その後で残り（防御系：防御力、HP、クリティカル抵抗）。
  • 最後の最後に、MP+50のノードを避けるルートに組み直す。ボードのリセットは安い。
  • 優先：{{ s('deadshot') }}、{{ s('snare-shot') }}、{{ s('suppressing-arrow') }}、{{ s('marking-shot') }}、{{ s('defiance') }}の青ノード。
  • グローバル版にアリエルはない：ボードは5枚で、Lv45のアスフェルはPvPダメージ増幅とPvPダメージ耐性だけ。PvEでは最初の4枚を埋める。
  • アスフェル（Lv45）はすべてPvPダメージ増幅とPvPダメージ耐性。これを取り、その前にトリニエルも取る。

{% endcall %} {% call section('stigmas', 'スティグマ', 'pve') %}

最初は各段階の効果を取るために均等に上げる（5 / 5 / 5、次に10）。バイゼルの権能20に足りるポイントが貯まったら、リセットして真っ先にそこへ振る。レンジャーが一気に強くなるのはここからだ。その後、祝福のボウ、支援射撃、グリフォンの矢を順に20にする。

    {% call skill('vaizels-authority', 'must', 'Lv20', upto=20) %}集中の眼とハンターの魂の効果が1.5倍。20ではクリティカルのたびに50%の確率ですべての再使用時間が1秒減り、DPSが大きく跳ね上がる。{% endcall %} {% call skill('bow-of-blessing', 'must', 'Lv10 → 20', upto=20) %}多段ヒット、クリティカルに比例した攻撃力、クリティカル ダメージ、強打。{% endcall %} {% call skill('supporting-fire', 'must', 'Lv10 → 20', upto=20) %}一緒に射撃してくれる球体を呼び出す。バイゼルの権能と再使用時間が同じなので、1つのボタンにまとめられる。{% endcall %} {% call skill('griffon-arrow', 'must', 'Lv10 → 20', upto=20) %}紅炎の持続ダメージ。マクロの最初のラインを担う。{% endcall %} {% call skill('explosive-arrow', 'opt', '代替 · 4枠目', upto=10) %}グリフォンの矢と同格の選択肢。LordRobsonは両者のダメージをほぼ同じと評価しており、aLuckyROは初日にグリフォンの矢の代わりに爆発の矢を5（再使用時間15秒減少）で使っている。Lv45で5枠目が開いたら両方取る。{% endcall %} {% call skill('arrow-storm', 'opt', 'レベリング', upto=5) %}レベリング中に群れを狩る範囲攻撃。{% endcall %}
{% endcall %} {% call section('macro', 'ローテーションとマクロ', 'pve') %}

AION 2には別々の仕組みが2つあり、このビルドは両方を使う。

  • ホットバーのライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと使用可能なスキルのうち優先度が最も高いものが発動し、AION 2では一番下のスロットが最優先になる。カードは各ラインをゲーム内と同じく上から下の順に表示している。
  • ゲーム内マクロ：キーを押している間、ホットバーのラインを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーのライン

重要なのはこの2本だけ。ホットバーのどのスロットに置いてもいい。

{% call hotline('1', 'グリフォンライン', ['griffon-arrow', 'snare-shot', 'burst-arrow']) %}捕縛の矢で対象を鈍化させ、破裂の矢が当たるようにする。{% endcall %} {% call hotline('2', '狂風ライン', ['gale-arrow', 'drill-dart', 'tempest-shot']) %}速射が隙間をすべて埋める。{% endcall %}

2. ゲーム内マクロ

スキルウィンドウ → Macroで、グリフォンライン、狂風ラインの順に追加し、それぞれ10msにする（10～20msの間にちょうどいい値を見つける人もいるので、試してみよう）。マクロはSettings → Key Settings → General → Macroで右クリックに割り当てる。

{{ macroseq([('グリフォンライン', '1 · 10ms'), ('狂風ライン', '2 · 10ms')]) }}
  • 操作モードはAION 2 control modeを使う。AION 1 modeではゲーム内マクロに制限がかかる。
  • 戦闘操作の設定でskill queueをONにする。
  • Key Settings → Quick Slotで、{{ s('deadshot') }}に2つ目のキー（マウスのサイドボタン）を割り当てる。

3. 実際に押すもの

  • 開幕バフは手動で：{{ s('bow-of-blessing') }}、{{ s('supporting-fire') }} + {{ s('vaizels-authority') }}（1ボタン、再使用時間が同じ）。その後に{{ s('marking-shot') }}とフルチャージの{{ s('deadshot') }}。
  • 長押し{{ s('snipe') }}を左クリック、マクロを右クリック、{{ s('deadshot') }}をサイドボタンで、3つ同時に押し続ける。
  • 維持{{ s('marking-shot') }}：精密の残りが約3秒を切ったらかけ直す（バフバーを見る）。精密：完璧+5%、クリティカル+300、必中の矢のダメージ+35%。
  • クールタイムごとバフをかけ直す。
{% endcall %} {% call section('recap', 'まとめ', 'pve') %}
  • スキル：必中の矢と狂風の矢は20、鋭穿の矢・狙撃・速射は16、残りは12。矢乱射は上げない。
  • スティグマ：まずバイゼルの権能を20、次に祝福のボウ、支援射撃、グリフォンの矢。5枠目が開いたら爆発の矢。
  • パッシブ：集中の眼、ハンターの決意、その次にハンターの魂。
  • ステータス：命中を上限まで、その後は攻撃力 / クリティカル。
  • アルカナ：必中の矢と狂風の矢に+4。
{% endcall %} {# ============================ Leveling ============================ #} {% call section('fight-lvl', t.lvl_combat, 'lvl') %}
  • 群れ：足元に{{ s('explosion-trap') }} → {{ s('snare-shot') }} → {{ s('drill-dart') }} + {{ s('tempest-shot') }}。敵は自分から罠に入ってくる。
  • エリート：{{ s('marking-shot') }}（精密） → {{ s('snare-shot') }} → {{ s('burst-arrow') }} → チャージした{{ s('deadshot') }}。正面で受けずにカイトする。
  • HPが減ったら：鋭穿の矢と破裂の矢はHPを吸収する。回復する前に、一歩下がって近接の間合いから出よう。
{% endcall %} {% call section('macro-lvl', 'レベリング用マクロ', 'lvl') %}

レベリング中とカンスト直後の数日向けの、簡単な構成。Grobsの序盤用マクロが元になっている。入れるのは連打するスキルだけで、バフ、スティグマの瞬間火力、間合いを詰めるスキルはそれぞれ別のキーに置く。

{{ hotline('1', 'ライン1', ['griffon-arrow', 'explosive-arrow'], []) }} {{ hotline('2', 'ライン2', ['drill-dart', 'gale-arrow', 'tempest-shot'], []) }}

ゲーム内マクロ：ライン1 → ライン2、それぞれ10msのディレイ。基本攻撃の{{ s('snipe') }}を左クリックで押しながら、同時にマクロのキーも押し続ける。

スキルが12～16に上がり、特化で再使用時間が変わってきたら、PvEタブのフル構成に切り替えよう。

{{ passives(['focused-eye', 'hunters-resolve', 'hunters-soul', 'concentrated-fire']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

レンジャーはボウで戦うDPSで、ほぼすべてのスキルの射程である約20mの距離から攻撃する。火力はトップクラスだが、生存力と補助性能は低いので、立ち位置がすべてを左右する。

ビルドを一言で

バフをかけ、対象に{{ s('marking-shot') }}（精密：クリティカル+300、{{ s('deadshot', False) }}のダメージ+35%）を維持したら、あとは{{ s('snipe') }}、マクロ、チャージした{{ s('deadshot') }}の3ボタンを押し続ける。

このガイドは、Whelps（韓国サーバーでCP 1Mのレンジャーメイン。グローバル版のテストもプレイ）がquestlogで公開しているシーズン1エンドゲームのPvEビルドに沿っている。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版サーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。レンジャーへの影響は次のとおり。

  • Lv37の時点でスティグマは4つ。グローバル版のテストはLv37までだった。Lv45で5枠目が開く可能性は高いが未確認。開いたら{{ s('explosive-arrow') }}を入れる。
  • 20に届くスキルはごく一部。スキルポイントで上げられるのは10まで。ディーヴァニオンで+4、リングで+2、アルカナで最大+4が乗る。シーズン1では必中の矢と狂風の矢を20にする前提で考え、アルカナの引きがよければ3つ目も20にする。
  • 命中の上限は不明。韓国ではルドラ向けで約1,300だった。グローバル版の数値はリリース後に判明する。
  • PvP：全員が同じ限られた装備からのスタートで、メタはまだ固まっていない。

最初は各段階の効果を取るために均等に上げる（5 / 5 / 5、次に10）。バイゼルの権能20に足りるポイントが貯まったら、リセットして真っ先にそこへ振る。レンジャーが一気に強くなるのはここからだ。その後、祝福のボウ、支援射撃、グリフォンの矢を順に20にする。

Fubgun（グローバル版）：最初は15 / 10 / 10 / 5（バイゼルの権能、祝福のボウ、支援射撃、爆発の矢）。バイゼルの権能20の後は、次のポイントを祝福のボウ15に振る。バイゼルの権能20はクリティカルが十分にあって初めて活きる。振り切る前に訓練用の人形で試そう。

    {% call skill('vaizels-authority', 'must', 'Lv20', upto=20) %}集中の眼とハンターの魂の効果が1.5倍。20ではクリティカルのたびに50%の確率ですべての再使用時間が1秒減り、DPSが大きく跳ね上がる。{% endcall %} {% call skill('bow-of-blessing', 'must', 'Lv10 → 20', upto=20) %}多段ヒット、クリティカルに比例した攻撃力、クリティカル ダメージ、強打。{% endcall %} {% call skill('supporting-fire', 'must', 'Lv10 → 20', upto=20) %}一緒に射撃してくれる球体を呼び出す。バイゼルの権能と再使用時間が同じなので、1つのボタンにまとめられる。{% endcall %} {% call skill('griffon-arrow', 'must', 'Lv10 → 20', upto=20) %}紅炎の持続ダメージ。マクロの最初のラインを担う。{% endcall %} {% call skill('explosive-arrow', 'opt', '代替 · 4枠目', upto=10) %}グリフォンの矢と同格の選択肢。LordRobsonは両者のダメージをほぼ同じと評価しており、aLuckyROは初日にグリフォンの矢の代わりに爆発の矢を5（再使用時間15秒減少）で使っている。Moxsyのレベリング構成も爆発の矢を使う。Fubgun：グリフォンの矢が15に届くまでは爆発の矢のほうが強く、グローバル版では15まで長くかかる。Lv45で5枠目が開いたら両方取る。{% endcall %} {% call skill('arrow-storm', 'opt', 'レベリング', upto=5) %}レベリング中に群れを狩る範囲攻撃。{% endcall %}
{% endcall %} {% call section('macro', 'ローテーションとマクロ', 'pve') %}

AION 2には別々の仕組みが2つあり、このビルドは両方を使う。

  • ホットバーのライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと使用可能なスキルのうち優先度が最も高いものが発動し、AION 2では一番下のスロットが最優先になる。カードは各ラインをゲーム内と同じく上から下の順に表示している。
  • ゲーム内マクロ：キーを押している間、ホットバーのラインを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーのライン

重要なのはこの2本だけ。ホットバーのどのスロットに置いてもいい。

{% call hotline('1', 'グリフォンライン', ['griffon-arrow', 'snare-shot', 'burst-arrow']) %}捕縛の矢で対象を鈍化させ、破裂の矢が当たるようにする。{% endcall %} {% call hotline('2', '狂風ライン', ['gale-arrow', 'drill-dart', 'tempest-shot']) %}速射が隙間をすべて埋める。{% endcall %}

2. ゲーム内マクロ

スキルウィンドウ → Macroで、グリフォンライン、狂風ラインの順に追加し、それぞれ10msにする（10～20msの間にちょうどいい値を見つける人もいるので、試してみよう）。マクロはSettings → Key Settings → General → Macroで右クリックに割り当てる。

{{ macroseq([('グリフォンライン', '1 · 10ms'), ('狂風ライン', '2 · 10ms')]) }}
  • 操作モードはAION 2 control modeを使う。AION 1 modeではゲーム内マクロに制限がかかる。
  • 戦闘操作の設定でskill queueをONにする。
  • Key Settings → Quick Slotで、{{ s('deadshot') }}に2つ目のキー（マウスのサイドボタン）を割り当てる。

3. 実際に押すもの

  • 開幕バフは手動で：{{ s('bow-of-blessing') }}、{{ s('supporting-fire') }} + {{ s('vaizels-authority') }}（1ボタン、再使用時間が同じ）。その後に{{ s('marking-shot') }}とフルチャージの{{ s('deadshot') }}。
  • 長押し{{ s('snipe') }}を左クリック、マクロを右クリック、{{ s('deadshot') }}をサイドボタンで、3つ同時に押し続ける。
  • 維持{{ s('marking-shot') }}：精密の残りが約3秒を切ったらかけ直す（バフバーを見る）。精密：完璧+5%、クリティカル+300、必中の矢のダメージ+35%。持続は15秒で、それより頻繁にかけ直すとDPSが落ちる。
  • クールタイムごとバフをかけ直す。

レベリングとLv45になってからの最初の数日は、MoxsyのRanger guide（グローバル版、10月5日）に沿っている。韓国版と台湾版の経験があるレンジャー、JohnPalの協力で作られたもの。

  • 群れ：レンジャーのスキルの多くは対象から4m以内にしか当たらないので、敵を1体ずつ倒さない。{{ s('snipe') }}で何体かに当てて釣り、{{ s('marking-shot') }}と{{ s('explosion-trap') }}でまとめてから、マクロを使う。
  • エリート：まず{{ s('marking-shot') }}（精密は戦闘中ずっと続く）。次にマクロ、そしてフルチャージの{{ s('deadshot') }}を一番大きな対象に撃つ。エリートがいるときに必中の矢を雑魚に使わない。
  • グロッキー：ボスが気絶しそうなときに{{ s('suppressing-arrow') }}。{{ s('arrow-scattershot') }}は使わない。グロッキー中のボスに長押ししても、通常のローテーションよりダメージが低い。

{{ passives(['attack-preparation', 'inspiring-spell', 'winds-promise', 'impact-hit']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

チャンターはワンドで近接戦闘をこなしながら、パーティー全体を強化する。どのパーティーにも欲しいバッファー兼サブヒーラーだ。火力トップは期待しないこと。装備が同じなら、チャンターとクレリックは与ダメージが最も低い2クラスになる。それでもパーティーの火力は上がり、倒れにくくなり、デバフも解除してもらえる。

このビルドを一言で

{{ s('undefeated-mantra') }}を常に有効にしておき、{{ s('spinning-strike') }}と{{ s('impactful-crush') }}で{{ s('dark-crush') }}を開くラインを連打する。一撃ごとに{{ s('onslaught') }}を挟み、岩撃砕が使えない時は{{ s('marchutans-wrath') }}を手動で使う。

岩撃砕の仕組み：遠距離スキルを使った直後の短い時間しか使えない。{{ s('spinning-strike') }}か{{ s('impactful-crush') }}の後は2秒、{{ s('marchutans-wrath') }}の後は3秒。スキルLv16で岩撃砕自体の再使用時間がなくなるので、その受付時間中は何度でも押せる。このビルドはすべて、この受付時間を開け続けるために組まれている。

PvEモードは、Arthars Gamingのグローバル版ローンチ向けチャンター入門ガイド（動画、9月26日公開。台湾サーバーでこのクラスを8か月プレイ）をコマ単位で読み取ってまとめた。レベリングはTitanTheFのシートに従う。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版のサーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。チャンターへの影響は次のとおり。

  • スティグマ枠は4つ、上限はLv20。チャンターは役に立つスティグマが枠より多いので、どの4つを選ぶかが本当の悩みどころになる（「スティグマ」参照）。
  • 序盤は再使用時間減少も戦闘速度も少ない。再使用時間を縮める特化はどれも価値が上がり、戦闘は台湾版より長引く。
  • シーズン1ではスキルLv20に届きにくい。まずは主要スキルの16を目指す。20は後からアルカナで届かせる。
  • パーティーの人数が増える（5人の遠征、10人の聖域）：クレリックがいると、チャンターのマントラは保護の光と重複しない（同じLvならこちらが優先）。波動撃のデバフもクレリックの弱化の烙印とは重複しない。
  • PvP：全員が同じ限られた装備から始まり、メタはまだ固まっていない。

アクティブスキルとパッシブは、グローバル版と韓国/台湾版のデータで同一。スティグマはLv25の段階がなくなる。

意味のあるスキルLvは12、16、20だけ。ここで新しい特化やスロットが開き、その間のLvはほとんど何も足さない。スキルポイントで10、ディーヴァニオンで+4、両方の指輪で+2、残りはアルカナ。まず主要スキルを16にしよう。

    {% call skill('dark-crush', 'must', '16 → 20', [3, 4]) %}メイン火力で、最初に16にするスキル。再使用時間削除がないとこのクラスは回らない。20では確定クリティカルを追加する。これで岩撃砕のすべてが風の約束のボーナスを丸ごと受けられる。{% endcall %} {% call skill('onslaught', 'must', '16 → 20', [3, 4]) %}あらゆる攻撃の合間に挟む基本攻撃。MPを回復し、回転撃の再使用時間を縮め、16で暴風砕が追加される。20の3つ目は好みで、火力かHP吸収を選ぶ。{% endcall %} {% call skill('spinning-strike', 'must', '16 → 20', [0, 2]) %}最も重い一撃のひとつ。30秒間のクリティカル ダメージ増幅+15%が重複し、岩撃砕も開く。20ではガードと回避を無視してクリティカルで的中する特化を追加する。治癒増幅は取らない。メインヒーラーではないからだ。{% endcall %} {% call skill('incandescent-blow', 'must', '16', [2, 4]) %}岩撃砕が閉じている間のつなぎ。単体相手に+12%と多段ヒット。3つ目に良い特化がないので16で十分。{% endcall %} {% call skill('recuperation', 'must', '12', [0, 3]) %}スティグマ以外で唯一の回復で、デバフ解除も担う。12で十分（notXeon、WallyJTV）：HP5%追加回復（基本の回復量は固定値）と連続発動+1回。デバフの多い戦闘では連続発動をデバフ2個解除に替える。16にして−3秒を取るのは、自分しかヒーラーがいない時だけ。{% endcall %} {% call skill('defiance', 'must', '16', [3, 4]) %}CC解除。強靭さの持続時間+2秒、その間ずっとダメージ耐性50%。7秒間、ギミックの中に立っていられる。{% endcall %} {% call skill('impactful-crush', 'opt', '12', [2, 3]) %}岩撃砕を開く遠距離スキル。移動しながら使えて、スキル速度も上がる。12で十分。16の特化はPvP向け。{% endcall %} {% call skill('wave-blow', 'opt', '12', [1, 3]) %}10秒間ボスの与ダメージ−15%、射程10m。モーションが他のスキルとかみ合わないので、隙がある時だけ押す。岩撃砕の代わりに使うのは厳禁。{% endcall %} {% call skill('rushing-smash', 'opt', '12', [2, 3]) %}敵を倒すと再使用時間が戻る突進スキル。群れから群れへ飛び込める。チャージの特化は絶対に取らない。チャージ スキルは火力ロスになる。{% endcall %} {% call skill('tremor-crush', 'opt', '12', [0, 1]) %}使った行動力が戻ってくる回避で、20mの突進にもなる。{% endcall %} {% call skill('heat-wave-blow', 'opt', '12', [2, 3]) %}威力は高いが、岩撃砕がローテーションの中心になった今のPvEでは使う隙がほとんどない。{% endcall %} {% call skill('gust-rampage', 'skip', '0–8') %}グロッキー状態の対象にしか使えず、ボスがグロッキーになるのは1戦で2〜3回。シーズン1ではポイントを割く価値がない。{% endcall %}

3つは確定で、4つ目は選択。上げる順番はこのとおりで、不敗のマントラをLv20にするのが何よりも先。

    {% call skill('undefeated-mantra', 'must', 'Lv20', upto=20) %}パーティーがチャンターを入れる理由そのもの。PvEダメージ増幅と耐性、クリティカル、命中、クリティカル ダメージ増幅、強打を全員に与える。最初にLv20にし、バーから外すことはない。{% endcall %} {% call skill('marchutans-wrath', 'must', 'Lv1', upto=1) %}岩撃砕を3秒間開く、3つ目の遠距離スキル。岩撃砕を使える時間がほぼ倍になる。1ポイントで十分で、上の段階はPvP向け。{% endcall %} {% call skill('focused-defense', 'must', 'Lv5', upto=5) %}Lv5で連続発動が2回になるガード。過小評価されがち：近接職が逃げ回らず、ほとんどの攻撃の間もボスに張り付いていられる。{% endcall %} {% call skill('sprint-mantra', 'opt', 'Lv10', upto=10) %}移動速度、受ける治癒量+10%、行動力の回復で、パーティーはほぼ無制限に回避できる。notXeonはダンジョンと周回で使い、PvPでは外す。回復量は微々たるものなので、10より上げない。{% endcall %} {% call skill('power-of-the-storm', 'must', 'Lv5 → 20', upto=20) %}10秒間、戦闘速度+20%、再使用時間−20%（パーティーには+20%と−10%）。notXeonはあらゆるコンテンツで採用している。まだ誰も戦闘速度を持っていない今は、最大級の火力バフのひとつ。Lv5で自身の再使用時間が30秒縮み、20で自分とパーティーの攻撃力が上がる。{% endcall %} {% call skill('healing-touch', 'opt', 'クレリック不在', upto=15) %}強力な緊急回復。HPが低いほど回復量が増え、15でデバフを5個解除する。自分しかヒーラーがいない時や、デバフの多い戦闘で取る。{% endcall %} {% call skill('impeding-authority', 'opt', '初見攻略', upto=15) %}パーティーにバリアを張る。パーティーがまだ戦闘に慣れていない間、実質HPが増える。{% endcall %} {% call skill('guardian-blessing', 'opt', '枠なし', upto=15) %}15で風の約束が1.5倍になり、確かな火力アップになる。ただし枠が4つでは、シーズン1に入れる余地はない。{% endcall %} {% call skill('obliterate', 'opt', 'グロッキー', upto=5) %}レベリング中の群れに使う範囲転倒。WallyJTVはグロッキーギミックのあるボス用に上限まで上げている。パーティーが必要とする時に、グロッキー ゲージ ダメージ量50を出せる。{% endcall %}

マントラはトグル式。一度有効にしたら、どのマクロにも入れない。もう一度押すと切れてしまう。{{ s('barrier-spell') }}、{{ s('ensnaring-mark') }}、{{ s('fracturing-blow') }}、{{ s('assault-shock') }}はPvEでは出番がない。

{% endcall %} {% call section('macro', 'マクロとローテーション', 'pve') %}

AION 2には別々の仕組みが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと、使えるスキルのうち優先度が最も高いものが発動する。AION 2では一番下のスロットが最優先。カードでは各ラインをゲーム内と同じく上から下へ並べている。
  • ゲーム内マクロ：キーを押している間、ホットバーボタンを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーライン

{% call hotline('E', '岩撃砕ライン', ['dark-crush', 'spinning-strike', 'impactful-crush', 'incandescent-blow']) %}受付時間が開いていれば岩撃砕が出る。閉じたら回転撃が開き直し、次に打撃砕が開く。両方が再使用時間中なら百裂撃でつなぐ。{% endcall %}

{{ s('marchutans-wrath') }}はこのラインに入れない。別のキーに置いて予備にする。遠距離スキルが両方とも再使用時間中の時や、ボスから離れざるを得なかった直後に、岩撃砕を開く手段になる。ラインに入れると、百裂撃がローテーションから押し出されてしまう。

岩撃砕が16になるまでは、その再使用時間がこのラインを崩す。岩撃砕がまだ再使用時間中なのにマクロが開くためのスキルを使ってしまい、3秒の受付時間が無駄になる。それまでのnotXeonの対処法：開くスキルを1つ別のキーに置き、岩撃砕が使えるようになった瞬間に自分で押す。

2. ゲーム内マクロ

2ステップ、各10ms。押しっぱなしにできるキーに置く（ほとんどの人は右クリック）。

{{ macroseq([('岩撃砕ライン', '10ms'), (skill_data('onslaught')[lang].name, '10ms')]) }}

3. 実際に押すもの

  • 押しっぱなしマクロのキー。
  • 連打{{ s('onslaught') }}（左クリック）と岩撃砕ライン自体。マクロだけでは足りず、自分で押した分がマクロのステップの間に入る。連打はキーボードやマウスのマクロ機能に任せてもいい。
  • 手動岩撃砕が閉じている時の{{ s('marchutans-wrath') }}、大技に合わせた{{ s('focused-defense') }}、デバフ解除や回復の{{ s('recuperation') }}、隙がある時だけの{{ s('wave-blow') }}、それと突進スキル。

Artharsのテストでのダメージ内訳：岩撃砕とその連続スキル貫通砕で約40%、続いて破裂撃、暴風砕、百裂撃、回転撃がそれぞれ約10%。だから岩撃砕を最初に16にし、撃破砕には暴風砕が必要になる。

  • スティグマ：不敗のマントラ20、疾風の権能5 → 20、マルクタンの怒り1、集中防御5。ダンジョンでは疾走のマントラ、グロッキーギミックには滅火。

  • マクロ：岩撃砕ライン → 撃破砕。マルクタンの怒りは手動。

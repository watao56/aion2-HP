グラディエーターはNCSoftの看板クラスで、韓国・台湾サーバーではずっとSティアを維持している。パーティーにバフを配り、準タンクもこなしつつ大ダメージを出せるうえ、ほかのクラスより判断することが少ない。木人相手ならソーサラーとアサシンがわずかに上だが、グラディエーターもすぐ後ろにつけていて、操作ははるかに簡単だ。

ビルドをひと言で

{{ s('overhead-slam') }}をスキルLv16〜20、{{ s('lunge-stance') }}をスティグマLv20にし、{{ s('rage-burst') }}で打ち下ろしを活性化する。それ以外はすべて補助。

{% endcall %} {% call section('intro-pvp', '概要', 'pvp') %}

PvPのグラディエーターは打たれ強い突撃役だ。距離を詰めて相手を転倒させ、その転倒に打ち下ろしを叩き込む。HP、ガード、自己回復が十分にあるので、乱戦のど真ん中でも生き残れる。PvPで最も人気のあるクラスのひとつなので、同職対決は覚悟しておこう。

優先順位：CC対策 → 張り付き → 相手の防御スキルが切れたらバースト。

グローバル版のPvPメタはまだ存在しない。このモードは韓国・台湾のPvPビルドとグローバル版クライアントのスキルデータを組み合わせたものなので、出発点として扱ってほしい。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版サーバーは2026年10月5日にオープンする(ファウンダー先行アクセスは9月30日から)。韓国・台湾サーバーとは別サーバーだ。グラディエーターにとっての影響は次のとおり。

  • スティグマスロットは4つ(6つではない)。シーズン1だけの予定。
  • スティグマの上限はLv20。Lv25の段階はグローバル版クライアントに存在しない。
  • シーズン1には英雄装備がないため、パッシブに回せる追加オプションが少ない。
  • ディーヴァニオンのボーナスが台湾より弱い。戦闘が長引くので、攻撃し続けられる時間がより重要になる。
  • パーティーが大きい：5人の遠征と10人の聖域があり、天族と魔族が一緒にマッチングできる。パーティーバフの価値が上がる。
  • PvP：全員が同じ限られた装備から始まり、メタもまだ固まっていない。

アクティブスキルとパッシブは、グローバル版と韓国・台湾版のデータで同一。スティグマのLv25段階がなくなるだけだ。

重要なメカニクスはひとつ：転倒

{{ s('overhead-slam') }}と{{ s('aerial-snare') }}は転倒状態の対象にしか当たらない(ボスは例外なので、PvEでは気にする必要がない)。バーストはすべて転倒から始まる：蹂躙の剣(確定)、回避後の突進一撃、足首斬り。例外は{{ s('rage-burst') }}で、対象に対して10秒間、打ち下ろしを活性化する。

    {% call skill('overhead-slam', 'must', '16 → 20', [2, 4]) %}転倒した対象へのお仕置き。韓国のPvPガイドはLv20の確定クリティカルを必須としている。これはLv20で開く3つ目のスロットに入る。{% endcall %} {% call skill('mocking-blade', 'must', '16', [3, 4]) %}3秒の確定転倒で、メインの開幕スキル。Lv16では転倒時間の延長と、ガードと回避の無視を取る。2回追加攻撃はLv20の3つ目のスロットまで待つ。{% endcall %} {% call skill('defiance', 'must', '16', [3, 4]) %}気絶、転倒、空中束縛、掴み、氷結、恐怖を解除する。必須。Lv16では強靭さ+2秒とダメージ耐性を取る。HP20%回復はLv20の3つ目のスロット。{% endcall %} {% call skill('aerial-snare', 'must', '16', [3, 4]) %}転倒した対象を打ち上げる追撃。PvEでは役に立たないが、ここでは主力。Lv16では強制落下の連続スキルと再使用時間半減を取る。空中束縛確率はLv20の3つ目のスロット。{% endcall %} {% call skill('rush-strike', 'opt', '12–16', [1, 3]) %}回避 → 転倒確率つきの突進。Lv16では射程の特化を転倒確率+25%に替えてもよい。{% endcall %} {% call skill('rending-blow', 'opt', '16', [2, 4]) %}PvPでもつなぎの攻撃とMP回復の要。{% endcall %} {% call skill('ruinous-blow', 'opt', '12–16', [1, 4]) %}3つ目の接近スキル。ガード・回避無視はテンプラー相手に強い。ただしこの特化はLv16が必要なので、Lv12では射程と追加ダメージを取る。{% endcall %} {% call skill('crushing-wave', 'opt', '16', [3, 4]) %}引き寄せでヒーラーや後衛の魔法職を前に引きずり出す。{% endcall %} {% call skill('ankle-slice', 'opt', '12', [2, 0]) %}転倒のチャンスを作るもうひとつの手段。{% endcall %} {% call skill('leaping-slam', 'opt', '12', [1, 3]) %}20mの跳躍。敵の集団に着地しても生き残れる。{% endcall %}

パッシブのポイントは潤沢で、たいていのパッシブは何も考えなくても最大になる。注意すべき罠がひとつと、後回しでいいものがひとつ。

  • {{ s('protection-armor') }}：ガード時にごくわずか回復するだけ。これが付いた装備やカードはオプションを付け直そう。
  • {{ s('destructive-impulse') }}：グロッキー状態の対象にだけ追加ダメージ。罠ではない。aLuckyROとSenはグロッキー中のために上げていて、{{ s('sword-aura-rampage') }}と効果が重なる。主要パッシブの後に取る。

{{ s('blood-absorption') }}は投資不要。攻撃が的中するたびに50%の確率で回復し、HPが50%まで減ると大きく即時回復する。グラディエーターがヒーラーなしでもやっていけるのはこのおかげだ。

  • 命中：プレイヤーはボスよりはるかに頻繁にガードや回避をする。

  • アルカナ：まず打ち下ろしを20に、次に蹂躙の剣、衝撃解除、空中結縛を16に。

AION 2には別々のツールが2つあり、このビルドは両方を使う。

  • ホットバーライン：複数のスキルをひとつのホットバーボタンに重ねたもの。押すと使用可能なスキルのうち優先度が最も高いものが発動し、AION 2では一番下のスロットが最優先になる。下のカードは各ラインをゲームと同じく上から下へ並べ、各スキルに優先順位の番号を付けている。
  • ゲーム内マクロ：キーを押している間、ホットバーラインを順番に押し、モーションの後隙をキャンセルしてくれる。再使用時間中のスキルは飛ばされる。通常攻撃(左クリック)はマクロに入れず、マクロキーと同時に押しっぱなしにする。そのほうがゲーム側がうまく挟み込んでキャンセルしてくれる。

グラディエーターに必要なのは6スキルを3ボタン：攻撃スキル4つとバフ2つ。

1. ホットバーライン

{% call hotline('右クリック', 'メインライン', ['rage-burst', 'overhead-slam', 'rending-blow']) %}激怒爆発は一番下のスロットに置く。理由は後述。{% endcall %} {% call hotline('E', '破滅の猛打ライン', ['ruinous-blow'], ['lifestealing-blade']) %}戦闘準備を付与する。吸血の剣はスティグマに入れている場合だけ追加する。{% endcall %} {% call hotline('R', 'バフライン', ['lunge-stance', 'zikels-blessing']) %}突撃姿勢の再使用時間減少のおかげで、どちらも切れずに回り続ける。{% endcall %}

2. ゲーム内マクロ

スキルウィンドウ → Macro。3つのラインをこの順に入れ、Delayはすべて10msにする(ボタン間の待ち時間で、Pingとは関係ない)。マクロのキーはSettings → Key Settings → General → Gameplay → Macroで割り当てる。押しっぱなしにするので、マウスのサイドボタンが理想的だ。

{{ macroseq([('メインライン', '右クリック · 10ms'), ('破滅の猛打ライン', 'E · 10ms'), ('バフライン', 'R · 10ms')]) }}

シーズン1のコツ(Grobs)：リリース直後は再使用時間が長いので、バフはタイミングを合わせて使うほうが価値が高い。バフラインをマクロから外し、ボスや大きな群れの直前に手動で押してもよい。

3. 実際に押すもの

  • 長押しマクロキーを戦闘中ずっと。
  • 連打右クリックのメインラインと、その上からEの破滅の猛打ライン。挟み込めるように、2つのラインは分けておく。
  • 手動{{ s('focused-block') }}(ガード = パーティーバフ)、{{ s('mocking-blade') }}(転倒+回復)、{{ s('leaping-slam') }}(接近)、群れには{{ s('crushing-wave') }}。

ボス戦の開幕

{{ s('lunge-stance') }} + {{ s('zikels-blessing') }}→{{ s('leaping-slam') }}で突入→{{ s('ruinous-blow') }}→マクロ長押し

ボスの最初の攻撃を{{ s('focused-block') }}でガードする。巧みな反撃ですぐにパーティー全体にバフがかかる。ボスごとに開幕の動きは違い、飛び込んでから先にガードし、バフはその後にしたほうがいい相手もいる。ボスを覚えて、ガードを組み込もう。

便利な設定(Grobs)：Esc → Settings → Info Display → Combat → Display boss orientation indicator。ボスの正面がどちらかを表示してくれる。グラディエーターは常に正面から殴りたい。

激怒爆発を一番下に置く理由

激怒爆発は常に維持すべきバフなので、最優先の一番下のスロットに置き、再使用時間が明けるたびに発動させる。打ち下ろしより上に置くと一度も発動しない。突撃姿勢のおかげで打ち下ろしは常に使える状態にあり、下のスロットが必ず優先されるからだ。メインラインにスキルを詰め込みすぎないこと。マクロのタイミングはフレームレートに左右され、打ち下ろしが少しでも遅れると、追加したスキルで得る分より損のほうが大きい。

ダメージの内訳

木人で1分間計測した結果：打ち下ろし(叩き上げ込み)> 切断の猛打 > 破滅の猛打 > 突撃姿勢 > 殺気破裂 > 激怒爆発。

マクロはテンポを保ってくれるだけで、代わりに戦ってはくれない。いつガードするか、いつ距離を詰めるか、いつ自己回復するかは自分で決める。シーズン1はステータスが弱く、ボス戦は数分かかるので、攻撃が止まる1秒1秒が響く。

キー配置はArtharsのアクションモードのもの(右クリック / E)。タブターゲットなら連打しやすいキーを2つ使えばよい。マクロスロットの順番は、韓国のビルドと同じライン単位の組み方に従っている。

ゲーム内マクロ：ライン1を、それぞれDelay 10msで入れる。通常攻撃の{{ s('keen-strike') }}(左クリック)とマクロキーを同時に押しっぱなしにする。

レベリング中の優先順位(Grobs)

  • パッシブ：まず{{ s('experienced-counterstrike') }}、次に{{ s('attack-preparation') }}。この時点で意味があるのはこの2つだけ。
  • ディーヴァニオン：スキルポイントでスキルは10まで上がり、そこから先はボードで上げる。65ポイントのルートで主力の攻撃スキル4つに+2がつくので、早いうちに12に届いて2つ目の特化が開く。下のボードを参照。
  • 16になったら：打ち下ろしと切断の猛打が16になったら左クリックの押しっぱなしをやめる。{{ s('keen-strike') }}がダメージロスになるからだ。マクロだけを押し、MP用に切断の猛打の「クリティカル的中時にMP50回復」を取る。

スキルが12〜16になり、特化で再使用時間が変わってきたら、PvEタブの完全版の構成に切り替えよう。

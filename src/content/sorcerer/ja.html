{{ passives(['robe-of-flame', 'fire-mark', 'robe-of-earth', 'grace-of-enhancement']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

ソーサラーは火と氷を操る遠距離の紙装甲アタッカー。ダメージ源は火で、{{ s('fire-mark') }}で対象に印を付け、{{ s('blaze') }}でそれを消費して大ダメージを出す。氷は鈍化・束縛・氷結で敵を近づけない役割。ダメージボーナスの半分はMP次第で、MPが50%以上ならクリティカルが上がり、25%以上ならダメージが20%増える。

ビルドをひと言で

マクロを1つ押しっぱなしにして{{ s('element-enhancement') }}と{{ s('wish-of-concentration') }}を維持しつつ、{{ s('flame-arrow') }}と火・氷のラインを交互に撃ってMPを半分以上に保つ。{{ s('hellfire') }}だけは手動で撃つ。

  • ターゲットモードで遊ぶ。ターゲットを固定していれば、通常攻撃の{{ s('flame-arrow') }}がスキルを使うたびに自動で再開し、MPも回復する。アクションモードではスキルのたびに止まるので、そのつどクリックし直す必要がある。
  • 段階は2つ。Lv45になった最初の数日はスキルが8〜10で、特化は1つずつ。カードに書いたMPとスピード系の特化を取る。カードのレベルとハイライトされた2つの特化は後の目標（16）で、EUTOPIAのグローバル版構成と韓国のガイドに基づく。

序盤の構成とマクロはaLuckyROのソーサラー初心者ガイド（動画、9月15日、台湾クライアント）と10月2日のグローバル版向けアップデートに、スキルの優先度とLv16の特化はEUTOPIAのグローバル版ビルド（Lv45、アイテムレベル1,260、10月3日）に従う。EUTOPIAは自分のパーティーでダメージ1位を取っているプレイヤー。スキル名とデータはグローバル版クライアントのもの。

{% endcall %} {% call section('global', 'グローバル版シーズン1：変更点', 'pve pvp') %}

グローバル版サーバーは2026年10月5日オープン（ファウンダー先行アクセスは9月30日から）。ソーサラーにとっての影響は次のとおり。

  • スティグマ枠は4つ、上限は20。台湾と韓国は6枠。ここで残した4つは、どちらのソースも最初に上げているもの。
  • スキルは20ではなく16。スキルを16より上に押し上げるのはアルカナと指輪で、どちらも入手に時間がかかる。
  • 序盤はMPが苦しい。MPは約3,000で再使用時間減少もない。序盤の特化はダメージではなく、MPとスキル速度のために取る。
  • PvP：全員が同じ限られた装備から始まり、メタはまだ固まっていない。

最終的には7つのスキルを16まで上げ（最優先は{{ s('hellfire') }}）、残りは12止まりかホットバーから外す。スキルがまだ8〜10のうちに取る1つの特化は、各カードに書いてある。

    {% call skill('hellfire', 'must', '16', [0, 4]) %}最大火力の一撃でビルドの中心。EUTOPIAの優先度1位。フルチャージして手動で撃つ。16までは「スキル速度30%増加」と火属性持続ダメージの特化（aLuckyRO）。16で持続ダメージを「再使用時間15秒減少」に替える。20で開く3枠目は「ガードと回避を無視して多段ヒットで的中」。{% endcall %} {% call skill('firestorm', 'must', '16', [0, 3]) %}再使用時間5秒でMP消費が重い。まず「MP消耗50%減少」を取る。12からは槍1本ごとに地獄の火炎の再使用時間が2秒減るので、2つはセットで使う。20では槍ごとのダメージ15%増加を足す。{% endcall %} {% call skill('bittercold-wind', 'must', '16', [0, 3]) %}束縛の領域スキル。持続時間1秒増加、12で「ガードと回避を無視してクリティカルで的中」（EUTOPIA）。Lv16の特化は氷結の再使用時間を縮めるだけなので、氷結をホットバーから外したら不要。{% endcall %} {% call skill('blaze', 'must', '16', [2, 3]) %}火の印状態の対象へのメインダメージで、MPも回復する。パーティーでは遅延ダメージと多段ヒット。ソロで硬いボスを相手にするときは、遅延ダメージをHP吸収に替える（aLuckyRO）。20では集中の祈願の再使用時間を減らす特化を足す。{% endcall %} {% call skill('wish-of-concentration', 'must', '16', [1, 3]) %}「攻撃力10%追加増加」と「戦闘速度10%増加」。どちらのソースもこの2つを取る。20では「すべてのスキル再使用時間10秒減少」を足す。{% endcall %} {% call skill('winters-shackles', 'must', '16', [2, 4]) %}的中時に5秒間PvEダメージ増幅が20%上がる。このスキルを上げる理由はこれ。16で再使用時間15秒減少。EUTOPIAは代わりに連続スキル追加の特化を取る。{% endcall %} {% call skill('flame-arrow', 'must', '16', [3, 4]) %}通常攻撃で、MP供給の要。最初の数日は「MP回復20%増加」、MPが持つようになったら多段ヒット50%増加。12で炎の矢自体が火の印を付与するようになり、16で炎爆発の再使用時間を初期化する。{% endcall %} {% call skill('ice-chain', 'opt', '12', [1, 3]) %}EUTOPIAは氷鎖、氷結、氷結爆発をホットバーから外している。挟み込むのに時間がかかるわりにダメージが伸びないため。aLuckyROは氷鎖を12で残す。1ヒットごとに冬の束縛の再使用時間が1秒減る。特化はスキル速度20%増加、MPが足りなければMP消耗量20%減少。{% endcall %} {% call skill('flame-scattershot', 'opt', '12', [2, 3]) %}グロッキー状態の対象にしか使えないので、マクロに入れておいてよい。移動可能になる特化を取り、12で多段ヒットを足す。{% endcall %} {% call skill('frost', 'opt', 'レベリング', [0, 2]) %}MPを200回復する。MPが足りないレベリング中は便利だが、グローバル版のエンドコンテンツ構成ではホットバーから外す。{% endcall %} {% call skill('defiance', 'opt', '12', [2, 3]) %}CC解除。解除時にHPが20%回復する。{% endcall %} {% call skill('frost-burst', 'skip', '不要') %}氷結状態の対象にしか使えない。グローバル版の構成には入らない。{% endcall %}

{% endcall %} {% call section('stigmas', 'スティグマ', 'pve') %}

上げる順番は元素強化 → 冷気暴風 → 火の障壁 → 遅延爆発。新キャラではおよそ5 / 5 / 5 / 1から始まる。

    {% call skill('element-enhancement', 'must', 'Lv20', upto=20) %}火属性と水属性の攻撃力が20%増加（20でさらに10%追加）。メインのバフで、使えるようになるたびに使う。最初に最大まで上げる。{% endcall %} {% call skill('cold-storm', 'must', 'Lv10', upto=10) %}凍傷付きの水属性持続ダメージ領域。領域内で攻撃を当てるたびに追加ダメージが入る。{% endcall %} {% call skill('fire-wall', 'must', 'Lv10', upto=10) %}火属性の持続ダメージ領域。残火で攻撃のたびに追加ダメージが入る。ボスが動かないときや、敵の群れが通り抜けるときに最も強い。{% endcall %} {% call skill('delayed-explosion', 'must', 'Lv10', upto=10) %}4秒間、対象が自分から受けるダメージが15%増加。Lv10で再使用時間が短くなる。最初は1ポイントで十分。{% endcall %} {% call skill('glacial-smite', 'opt', '代替', upto=10) %}即発の大きな範囲攻撃で、群れ相手ほど強い。短い戦闘や周回で冷気暴風と入れ替える。{% endcall %} {% call skill('divine-burst', 'opt', '代替', upto=10) %}当てると自分が対象から後方へ飛び退く攻撃。10でHP吸収が付く。シャードに余裕が出てからの保険。{% endcall %} {% call skill('steel-barrier', 'opt', '代替', upto=10) %}最大HPの16%分のバリア。ソロのレベリング中は入れておき、何度も倒されるボス相手では冷気暴風と入れ替える（EUTOPIA）。{% endcall %}

aLuckyROの台湾版構成はスティグマ6枠で、この4つに氷河強打と神聖爆発を加えている。EUTOPIAはグローバル版でちょうどこの4つを使い、パーティーがグロッキーチェックを落とすときは神聖爆発に入れ替える。

{% endcall %} {% call section('macro', 'マクロとローテーション', 'pve') %}

AION 2には別々の仕組みが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと、使えるスキルのうち優先度が最も高いものが発動する。AION 2では一番下のスロットが最優先。カードでは各ラインをゲーム内と同じく上から下へ並べている。
  • ゲーム内マクロ：キーを押している間、ホットバーのボタンを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーライン

{% call hotline('4', 'バフライン', ['element-enhancement', 'bittercold-wind', 'delayed-explosion']) %}元素強化は使えるようになり次第発動。その次に束縛の領域と、ダメージ+15%のデバフ。{% endcall %} {% call hotline('5', '集中ライン', ['wish-of-concentration', 'cold-storm', 'fire-wall']) %}まず2つ目のバフ、次に対象の足元へ2つの領域。{% endcall %} {% call hotline('1', '火ライン', ['blaze', 'firestorm']) %}対象に火の印があれば炎爆発、炎の槍は再使用時間5秒ごとに。{% endcall %} {% call hotline('T', '氷ライン', ['winters-shackles', 'ice-chain']) %}ダメージバフのために冬の束縛。氷鎖を残しているなら残りの時間を埋める。外しているならこのラインは冬の束縛だけ。{% endcall %}

{{ s('flame-arrow') }}は単独でR、{{ s('hellfire') }}は2、{{ s('flame-scattershot') }}は3に置く。

2. ゲーム内マクロ

マクロキーはSettings → Key settings → Gameplay → Macroで設定する。全ステップを同じディレイにする。

{{ macroseq([('バフライン', '4'), ('集中ライン', '5'), (skill_data('flame-arrow')[lang].name, 'R'), ('火ライン', '1'), (skill_data('flame-arrow')[lang].name, 'R'), ('氷ライン', 'T'), (skill_data('flame-scattershot')[lang].name, '3')]) }}
  • ディレイ：Pingが50未満なら10ms、Pingが80〜100以上なら40〜50ms。
  • 確認方法：マクロ実行中に自キャラを見る。後ろに残像（「影」）が出ていればモーションがキャンセルできていて、ディレイは適切。
  • 炎の矢が2回ある理由：重いスキルの合間にMPを補給して50%以上を保ち、MP条件のパッシブを2つとも有効にしておくため。

ステップはaLuckyROのマクロ画面（9月15日、台湾クライアント）から取り、EUTOPIAのグローバル版構成に合わせて氷結と氷結爆発を外した。最後のステップを火炎乱射にしたのはaLuckyROの説明による（グロッキー状態のボスには勝手に発動する）。

3. 実際に押すもの

  • 押しっぱなしマクロキー。ほかには何も押さない。
  • 手動{{ s('hellfire') }}：止まってフルチャージし、マクロに戻る。
  • MP不足それでもMPが減るなら、マクロを離して{{ s('flame-arrow') }}を何発か撃ってから再開する。

4. 後半：手動でバースト

装備に再使用時間減少が付いてきたら、韓国のプレイヤーはバフをマクロから外し、手動でバーストのタイミングを作っている。

  1. タンクが釣る直前に{{ s('delayed-explosion') }}。
  2. {{ s('element-enhancement') }}と{{ s('wish-of-concentration') }}。
  3. ボスの足元に{{ s('fire-wall') }} + {{ s('cold-storm') }}。
  4. {{ s('bittercold-wind') }}、続けて{{ s('winters-shackles') }}でダメージ増幅+20%。
  5. {{ s('hellfire') }}を3段階までチャージし、その後マクロ。

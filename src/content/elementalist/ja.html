{{ passives(['spirit-protection', 'revitalization-contract', 'spirit-strike', 'mental-focus']) }} {% endcall %} {% call section('intro', '概要', 'pve') %}

スピリットマスターは唯一の召喚職。精霊がそばで戦い、精霊がスキルを使うたびに元素を1つ獲得する。元素が4つそろうと{{ s('elemental-fusion') }}が使える。ダメージの大半は元素融合と精霊から出る。中でも{{ s('summon-ancient-spirit') }}と{{ s('summon-fire-spirit') }}が大きい。

ビルドを一言で

先にバフ、それから召喚。精霊は召喚された瞬間のプレイヤーの能力値をコピーする。{{ s('cold-shock') }}の攻撃力バフを5スタック維持し、バフと古代の精霊で開幕して、元素融合は使えるようになるたびにマクロに撃たせる。

  • スナップショットのルール。精霊のダメージは召喚した時点の能力値とバフで決まる。召喚後にかけたバフはその精霊には乗らない。バフなしで古代の精霊を呼ばないこと。
  • 通常攻撃を挟む。冷気衝撃は1回当てるごとに攻撃力+2%、最大5スタック。これが切れると自分と以後に召喚する精霊すべての攻撃力が10%下がる。次の召喚より、通常攻撃を1回挟むほうが価値が高い。
  • 長期戦が得意。バフと持続ダメージに頼るクラスなので、戦闘が長引くほど強くなる。逆に、スキルをすべてクールタイムにした状態で倒れると、失うものが最も大きい。

このガイドはEvripidesによるスピリットマスターの文章ガイド、シーズン1グローバル版(aion2sm.com、700k CPで執筆、9月29日更新)に沿っている。DankRNGの動画もこのガイドを基にしている。初日の特化はaLuckyROのグローバル版向け動画で補った。元のガイドは台湾版と韓国版を基にしたもので、作者はリリース後に更新する予定。

{% endcall %} {% call section('intro-pvp', '概要', 'pvp') %}

PvPのスピリットマスターは粘り勝ちするカイト職。機動力はレンジャーに、バーストはソーサラーに劣るが、遠距離職の中では群を抜いて硬い。恐怖、バフ解除、そして自分が射程外にいても攻撃を続ける精霊を持つ。

  • 恐怖は倒すためではなく制御のために使う。敵を引き剥がしたり、敵の{{ s('defiance', False) }}を吐かせたりするのに使う。ダメージ源は元素融合、呪い、精霊。
  • 勝敗はタイミングで決まる。相手クラスのスキルを把握しておく。防御スキルを早すぎても遅すぎても負ける。
  • {{ s('summon-earth-spirit') }}は挑発を入れる。挑発は衝撃解除では解除できない。

PvPモードは同じガイドの「PvP Starter」ビルド(9月29日更新)に沿っている。

2つのキーを押しっぱなしにして戦う。{{ s('cold-shock') }}を左クリック、マクロを右クリックで押しっぱなしにしたまま移動し、残りは手動で押す。もともと右クリックにあったホットバーのラインはTに移す。

1. ホットバーのライン

{% call hotline('1', '精霊ライン', ['elemental-fusion', 'summon-water-spirit', 'summon-earth-spirit', 'summon-fire-spirit']) %}連打する。元素融合は使えるようになり次第撃ち、その後に精霊が続く。火の精霊は最後に呼ぶので、一番長く場に残る。{% endcall %} {% call hotline('7', 'バフ + 古代の精霊', ['enhance-spirits-benediction', 'flame-blessing', 'summon-ancient-spirit']) %}バフを古代の精霊より前に置くので、召喚がバフをコピーする。{% endcall %} {% call hotline('T', '火力ライン', ['jointstrike-corrode', 'jointstrike-curse', 'dimensional-control', 'combustion']) %}ダメージ順に並べる。協力攻撃：腐食は使えるようになった瞬間に入れる。{% endcall %}

3. 戦闘の流れ

  1. 開幕は{{ s('flame-blessing') }} → {{ s('enhance-spirits-benediction') }} → {{ s('summon-ancient-spirit') }}。バフを召喚より先に入れる。
  2. 精霊ラインと協力攻撃：腐食。その後マクロを起動し、2つ押しっぱなしの操作に移る。
  3. 精霊を回し続ける。バフは古代の精霊用に温存せず、使えるようになったらすぐかけ直す。
  4. 冷気衝撃の5スタックが切れそうなら、次の召喚より通常攻撃を1回挟むほうがいい。

通常攻撃をうまく挟めるかはPingしだい。作者の目安は戦闘速度65%以上、Ping約60ms未満。aLuckyROの最初の1週間向けのアドバイスは、クラスに慣れるまではマクロなしで遊ぶこと。精霊をすべて解除する操作は押しやすいキーに割り当てておく。

{{ s('summon-water-spirit') }}でレベルを上げる(ダメージとMP)。MP回復には{{ s('cold-shock') }}を押しっぱなしにし、精霊ラインと融合ラインはゲーム内マクロに回させる。

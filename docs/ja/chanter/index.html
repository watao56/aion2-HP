概要

チャンターはワンドで近接戦闘をこなしながら、パーティー全体を強化する。どのパーティーにも欲しいバッファー兼サブヒーラーだ。火力トップは期待しないこと。装備が同じなら、チャンターとクレリックは与ダメージが最も低い2クラスになる。それでもパーティーの火力は上がり、倒れにくくなり、デバフも解除してもらえる。

このビルドを一言で

不敗のマントラを常に有効にしておき、回転撃と打撃砕で岩撃砕を開くラインを連打する。一撃ごとに撃破砕を挟み、岩撃砕が使えない時はマルクタンの怒りを手動で使う。

岩撃砕の仕組み：遠距離スキルを使った直後の短い時間しか使えない。回転撃か打撃砕の後は2秒、マルクタンの怒りの後は3秒。スキルLv16で岩撃砕自体の再使用時間がなくなるので、その受付時間中は何度でも押せる。このビルドはすべて、この受付時間を開け続けるために組まれている。

PvEモードは、Arthars Gamingのグローバル版ローンチ向けチャンター入門ガイド（動画、9月26日公開。台湾サーバーでこのクラスを8か月プレイ）をコマ単位で読み取ってまとめた。レベリングはTitanTheFのシートに従う。

パッチ シーズン1. ビルドはグローバルサーバーのガイドと照らして確認済み：スティグマ4つ、上限20。

グローバル版シーズン1：変更点

グローバル版のサーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。チャンターへの影響は次のとおり。

  • スティグマ枠は4つ、上限はLv20。チャンターは役に立つスティグマが枠より多いので、どの4つを選ぶかが本当の悩みどころになる（「スティグマ」参照）。
  • 序盤は再使用時間減少も戦闘速度も少ない。再使用時間を縮める特化はどれも価値が上がり、戦闘は台湾版より長引く。
  • シーズン1ではスキルLv20に届きにくい。まずは主要スキルの16を目指す。20は後からアルカナで届かせる。
  • パーティーの人数が増える（5人の遠征、10人の聖域）：クレリックがいると、チャンターのマントラは保護の光と重複しない（同じLvならこちらが優先）。波動撃のデバフもクレリックの弱化の烙印とは重複しない。
  • PvP：全員が同じ限られた装備から始まり、メタはまだ固まっていない。

アクティブスキルとパッシブは、グローバル版と韓国/台湾版のデータで同一。スティグマはLv25の段階がなくなる。

パッシブ

スキルポイントはほぼすべてのパッシブを最大にできるだけある。装備のオプション枠は少ないので、上位3つに回す。

パッシブ優先度理由
攻撃準備1 · 最大PvEダメージ増幅、防御力、命中が固定値で上がる。常に効果がある。
鼓舞の呪文2 · 最大クリティカルと完璧。風の約束はクリティカル時にしか効果がないので、こちらが先（notXeon、WallyJTV）。
風の約束3 · 最大クリティカル ダメージ増幅と追加ダメージ。岩撃砕の確定クリティカルと相性がいい。Lv制限はないので、習得したらすぐ最大にする。
衝撃的中4 · 最大強打。そのまま火力が上がる。
保護陣最大HPが半分を切ると大きなバリア、攻撃が当たるたびにパーティーへ小さなバリア。防御系パッシブでは最良で、火力系の次に最初に上げる。
大地の約束5対象のPvEダメージ耐性を下げるが、効いているのは時間の半分ほどで、クレリックの苦痛の連鎖とも効果がかぶる。
生命の祝福、生存意志ポイントのみスキルポイントだけで最大にできる。装備のオプション枠は使わない。
十字防御、激怒の呪文不要PvEではほとんど何もしない。装備に付いたら再設定で消す。

装備とステータス

  • 指輪：アクティブスキルを付けられる唯一の場所。オプション4〜5行（製作品の指輪は1行多い）で、主要スキルを14から16に上げる。
  • 武器とガーダー：スキルは絶対に付けない。ダメージ系のオプションのほうが価値が高い。
  • パッシブはそれ以外の部位で上げる。グローバル版の装備はそこにMight、Precision、戦闘速度も付くので、台湾版よりパッシブのオプションは少なくなると見ておこう。
  • 命中は序盤に足りなくなる。不足しているとボスを背後から殴るしかなく、正面では武器ガードされる。
  • 魔石：攻撃力、クリティカル、命中。ガーダー（サブ武器）は+10まで。

アルカナ

シーズン1のカードは5種類、セットは2つ。Artharsの選択は太初の活力のカード3枚に、魔力鎧の鐘と鏡。太初の活力を4枚（PvE攻撃力+150）でもいい。

カードステータスセット狙うスキル
聖杯Time（戦闘速度）太初の活力まだ20に届いていない主要スキルならどれでも
羊皮紙Life太初の活力岩撃砕、撃破砕、回転撃
コンパスFreedom（命中）太初の活力百裂撃、快癒の呪文。衝撃解除でもよい
鐘Destruction（攻撃力）魔力鎧攻撃準備
鏡Wisdom（強打）魔力鎧衝撃的中、風の約束

カードを強化すると、付いているスキルが最大+4までランダムに上がる。目安は+2。それで足りる：ポイントで10、ディーヴァニオンで4、カードで2の合計16になり、指輪のオプションは他のスキルに回せる。

これらのカードに投資しすぎないこと。シーズン2で新しいカードが来ればすぐ入れ替わる。鏡のIllusion（再使用時間）は、Wisdomに代わる完全サポート向けの選択肢。

ディーヴァニオン ボード

ディーヴァニオンはスキルを10から14に上げ、ステータスも伸ばす。青いノードは1つごとに、対応するスキルをLv+1する。

  • 優先順：岩撃砕、撃破砕、回転撃、百裂撃の青ノード、次にオレンジのノード。
  • 優先順：打撃砕、波動撃、衝撃解除の青ノード。
  • グローバル版にアリエルはない：ボードは5枚で、Lv45のアスフェルはPvPダメージ増幅とPvPダメージ耐性だけ。PvEでは最初の4枚を埋める。
  • アスフェル（Lv45）はすべてPvPダメージ増幅とPvPダメージ耐性。取っておこう。その前にトリニエルも。

マクロとローテーション

AION 2には別々の仕組みが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと、使えるスキルのうち優先度が最も高いものが発動する。AION 2では一番下のスロットが最優先。カードでは各ラインをゲーム内と同じく上から下へ並べている。
  • ゲーム内マクロ：キーを押している間、ホットバーボタンを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーライン

E岩撃砕ライン
  1. 4 百裂撃
  2. 3 打撃砕
  3. 2 回転撃
  4. 1 岩撃砕

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

受付時間が開いていれば岩撃砕が出る。閉じたら回転撃が開き直し、次に打撃砕が開く。両方が再使用時間中なら百裂撃でつなぐ。

マルクタンの怒りはこのラインに入れない。別のキーに置いて予備にする。遠距離スキルが両方とも再使用時間中の時や、ボスから離れざるを得なかった直後に、岩撃砕を開く手段になる。ラインに入れると、百裂撃がローテーションから押し出されてしまう。

岩撃砕が16になるまでは、その再使用時間がこのラインを崩す。岩撃砕がまだ再使用時間中なのにマクロが開くためのスキルを使ってしまい、3秒の受付時間が無駄になる。それまでのnotXeonの対処法：開くスキルを1つ別のキーに置き、岩撃砕が使えるようになった瞬間に自分で押す。

2. ゲーム内マクロ

2ステップ、各10ms。押しっぱなしにできるキーに置く（ほとんどの人は右クリック）。

  1. 1岩撃砕ライン10ms
  2. 2撃破砕10ms

3. 実際に押すもの

  • 押しっぱなしマクロのキー。
  • 連打撃破砕（左クリック）と岩撃砕ライン自体。マクロだけでは足りず、自分で押した分がマクロのステップの間に入る。連打はキーボードやマウスのマクロ機能に任せてもいい。
  • 手動岩撃砕が閉じている時のマルクタンの怒り、大技に合わせた集中防御、デバフ解除や回復の快癒の呪文、隙がある時だけの波動撃、それと突進スキル。

Artharsのテストでのダメージ内訳：岩撃砕とその連続スキル貫通砕で約40%、続いて破裂撃、暴風砕、百裂撃、回転撃がそれぞれ約10%。だから岩撃砕を最初に16にし、撃破砕には暴風砕が必要になる。

まとめ

  • スキル：岩撃砕、撃破砕、回転撃は16 → 20。百裂撃、衝撃解除は16。快癒の呪文とその他は12。
  • スティグマ：不敗のマントラ20、疾風の権能5 → 20、マルクタンの怒り1、集中防御5。ダンジョンでは疾走のマントラ、グロッキーギミックには滅火。
  • パッシブ：攻撃準備、鼓舞の呪文、風の約束、衝撃的中。保護陣も最大まで。
  • マクロ：岩撃砕ライン → 撃破砕。マルクタンの怒りは手動。

レベリング中の戦い方

  • 群れ：突進撃破で突入（敵を倒すとリセット）→ 滅火 → 砕ライン + 撃破砕。
  • エリート：打撃砕（気絶）→ 岩撃砕 → 波動撃 → 回転撃 → もう一度岩撃砕。
  • MP：撃破砕は当たるたびにMPを回復する。合間に挟むのを止めない。
  • HPが減ったら：快癒の呪文。疾走のマントラも攻撃が当たると回復する。

レベリング用マクロ

レベリング中、岩撃砕が16になる前は、TitanTheFのもっとシンプルな構成がLv1から使える。右クリックに砕ライン、左クリックに撃破砕、ホイールクリックにゲーム内マクロ（疾風の権能 → 撃破砕 → 波ライン → 撃破砕）。1〜45の序盤ビルド：撃破砕、百裂撃、回転撃、突進撃破を12、それ以外は8。

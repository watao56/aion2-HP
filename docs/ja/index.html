全ガイド共通の内容

PvE / PvP / レベリング

スイッチひとつでページ全体が切り替わる。PvE専用ビルド、PvP専用ビルド、レベリング用チェックリストから選べる。

グローバル版クライアントのデータ

スキル名、特化、スティグマのティアは韓国版クライアントではなく、グローバル版のデータベースから取得している。

進捗管理

レベリングの手順を終えるごとにチェックを付けよう。進捗はクラスごとにブラウザへ保存される。

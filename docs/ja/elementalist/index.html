概要

スピリットマスターは唯一の召喚職。精霊がそばで戦い、精霊がスキルを使うたびに元素を1つ獲得する。元素が4つそろうと元素融合が使える。ダメージの大半は元素融合と精霊から出る。中でも召喚：古代の精霊と召喚：火の精霊が大きい。

ビルドを一言で

先にバフ、それから召喚。精霊は召喚された瞬間のプレイヤーの能力値をコピーする。冷気衝撃の攻撃力バフを5スタック維持し、バフと古代の精霊で開幕して、元素融合は使えるようになるたびにマクロに撃たせる。

  • スナップショットのルール。精霊のダメージは召喚した時点の能力値とバフで決まる。召喚後にかけたバフはその精霊には乗らない。バフなしで古代の精霊を呼ばないこと。
  • 通常攻撃を挟む。冷気衝撃は1回当てるごとに攻撃力+2%、最大5スタック。これが切れると自分と以後に召喚する精霊すべての攻撃力が10%下がる。次の召喚より、通常攻撃を1回挟むほうが価値が高い。
  • 長期戦が得意。バフと持続ダメージに頼るクラスなので、戦闘が長引くほど強くなる。逆に、スキルをすべてクールタイムにした状態で倒れると、失うものが最も大きい。

このガイドはEvripidesによるスピリットマスターの文章ガイド、シーズン1グローバル版(aion2sm.com、700k CPで執筆、9月29日更新)に沿っている。DankRNGの動画もこのガイドを基にしている。初日の特化はaLuckyROのグローバル版向け動画で補った。元のガイドは台湾版と韓国版を基にしたもので、作者はリリース後に更新する予定。

概要

PvPのスピリットマスターは粘り勝ちするカイト職。機動力はレンジャーに、バーストはソーサラーに劣るが、遠距離職の中では群を抜いて硬い。恐怖、バフ解除、そして自分が射程外にいても攻撃を続ける精霊を持つ。

  • 恐怖は倒すためではなく制御のために使う。敵を引き剥がしたり、敵の衝撃解除を吐かせたりするのに使う。ダメージ源は元素融合、呪い、精霊。
  • 勝敗はタイミングで決まる。相手クラスのスキルを把握しておく。防御スキルを早すぎても遅すぎても負ける。
  • 召喚：地の精霊は挑発を入れる。挑発は衝撃解除では解除できない。

PvPモードは同じガイドの「PvP Starter」ビルド(9月29日更新)に沿っている。

パッチ シーズン1. ビルドはグローバルサーバーのガイドと照らして確認済み：スティグマ4つ、上限20。

3. 戦闘の流れ

  1. 開幕は焔の祝福 → 強化：精霊の加護 → 召喚：古代の精霊。バフを召喚より先に入れる。
  2. 精霊ラインと協力攻撃：腐食。その後マクロを起動し、2つ押しっぱなしの操作に移る。
  3. 精霊を回し続ける。バフは古代の精霊用に温存せず、使えるようになったらすぐかけ直す。
  4. 冷気衝撃の5スタックが切れそうなら、次の召喚より通常攻撃を1回挟むほうがいい。

通常攻撃をうまく挟めるかはPingしだい。作者の目安は戦闘速度65%以上、Ping約60ms未満。aLuckyROの最初の1週間向けのアドバイスは、クラスに慣れるまではマクロなしで遊ぶこと。精霊をすべて解除する操作は押しやすいキーに割り当てておく。

戦闘の始め方

PvPではマクロにほとんど頼らない。マクロで回すのは右クリックの元素融合 → 召喚：地の精霊だけ。残りはすべてタイミング勝負。

仕掛けられたとき

最初のCCは衝撃解除ですぐ解除する。命令：身代わりは次の追撃まで我慢して取っておく。

自分から仕掛けるとき

強化：精霊の加護 + カイジネルの権能→召喚：地の精霊 + 協力攻撃：呪い→召喚：古代の精霊→敵のポーション後に協力攻撃：腐食

魂の絶叫は、地の精霊がCCを入れられなかったときか、敵の衝撃解除がなくなってから使う。衝撃解除を吐かせるには空間支配で束縛する。

相手対処
グラディエーター、クレリック無敵スキルには魔法強奪。回復対策は協力攻撃：呪いを先に入れ、次に協力攻撃：腐食。
レンジャーバフをかけた直後に魔法強奪。継戦能力には協力攻撃：腐食。
アサシン仕掛けてきたら命令：身代わり。
ソーサラー凍らされたら命令：身代わり。ダッシュはメテオ用に取っておく。メテオは回避とガードを無視する。

  2. 3 協力攻撃：呪い
  3. 2 空間支配
  4. 1 元素融合

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

元素融合と空間支配は精霊が使えるようにした瞬間に発動し、火炎全焼が隙間を埋める。

ゲーム内マクロ(Skill window → Macro)。各スロットのディレイは10ms：

  1. 1精霊ライン1 · 10ms
  2. 2融合ライン2 · 10ms
  • 押しっぱなし冷気衝撃(左クリック)とマクロキーを同時に。
  • 手動強化：精霊の加護、次に召喚：古代の精霊(先にバフ。古代の精霊は30秒しかいない)。

最初に変更する設定

2分しかないなら、効果が大きいのはこの設定。詳細と理由は下の各セクションにある。

Key Settings General

Macro

キーを割り当てる：右クリックが定番

初期状態ではキーが未設定で、割り当てないとゲーム内マクロはまったく動かない。

Separate Defiance Hotkey

ON + 専用キー

Spaceのままだと、Defianceがジャンプ・滑空と同じキーになる。拘束中に連打すると滑空して飛び立ってしまう。

Fly Up, Fly Down

押しやすいキー

初期設定はCtrl+RとCtrl+Fで、どちらも常に使う。

Interact

2つ目のキー：F + Z

2つを交互に連打すると、クエストの会話がかなり速く進む。

戦闘

In Combat

街中を走り回ってもバフスクロールが減らなくなる。

Controls → Skill Queue

ON

マクロとの相性が最も良い。

Target Scanning → Preferred Search Direction

Front of Camera

Tabで見ている方向の対象を選べる。

Target Scanning → Detailed Settings

Priority Ranking、Hostile Playersを最優先

PvP用：Tabでモンスターより先にプレイヤーを選ぶ。

Info Display Combat

Aggro Range Display

モンスターが反応する範囲が見える。

Player Particle Effect Display

Identical Player Appearance, [Abyss] Display as Tier Icon

Combat Controls

Control Mode：AION 2とAION 1のどちらにするか。AION 2はアクションモードで、照準が画面中央にあり、カメラがマウスに追従する。AION 1は従来型で、カーソルを自由に動かし、右クリックを押している間だけカメラが回る。好みの問題だが、マクロにはAION 2のほうが向いている。AION 1モードでは左右のマウスボタンを割り当て直せない。 ▶ 0:08

Control Mode

AION 2

マウスボタンにマクロを置くならこちらが向いている。上を参照。

Display Distance to Aimed Target

ON

ネームプレートの上に対象までの距離が表示される。

Adjust Aim Position

好みで

照準を画面の上下に動かす（動画では188px）。

Select Aimable Target

Hostile Target

そうしないと照準が味方も拾ってしまう。味方を対象にする場面はほとんどなく、攻撃中の相手に合わせたままのほうがいい。

Pursue Targets with Skill Activation

遠距離はOFF、近接はどちらでも

ONだと、射程外でスキルを押したときに対象まで歩いてから発動する。OFFのほうが操作しやすい。

Auto Target Upon Skill Use

オープンワールドの周回はON（初期値：OFF）

対象を選んでいなくても、スキルが最も近い敵を自動で選ぶ。マクロを押しっぱなしで走り回ればモンスターからモンスターへ移れる。Grobsは周回のときは必ずONにしていて、特に遠距離クラスで有効。Whelpsは周回以外ではOFF。

Set Main Target Upon Attack

2通り、下を参照（初期値：ON、左右クリックともON）

攻撃で対象を固定するかどうか。Whelps：ON、左クリックON、右クリックOFF。Grobs：近接ではOFF。

Skill Queue

ON

別のスキルの発動中に押したスキルが予約される。マクロと組み合わせると最も効果が高い。

▶ 0:50 ▶ Grobs 1:40

ソフトロックとハードロック

敵に照準を合わせると周りに白い円が出る。これがソフトロックで、スキルはその敵に向かうが、別の方向に照準を向けるとすぐ対象が変わる。HPバーに矢印が2つ付いていればハードロックで、変更するまで対象が維持される。初期状態では攻撃するとハードロックになり、Tabは常にハードロックになる。 ▶ Grobs 0:39

  • Set Main Target Upon Attack → OFF（Grobs、近接）：攻撃で対象が固定されなくなり、止まらずに次々と対象を切り替えられる。モンスターの群れに向いている。ボスにはTabで固定する。
  • ON、左クリックON、右クリックOFF（Whelps、レンジャー）：左ボタンで対象を選んで固定し、マクロを置いている右ボタンでは誤って対象が切り替わらない。

Combat Target Scanning

Preferred Search Direction

Front of Camera（初期値：None）

Tabがカメラの向いている方向の対象を探すので、選ばれる対象を自分で決められる。

Target Scanning Detailed Settings

Priority Ranking（初期値：Closest First）

PvPをするなら：距離順ではなく、自分で決めた優先順位で対象が選ばれる。アビスではモンスターとプレイヤーが入り混じるので、Tabでプレイヤーを選ばせたい。

▶ 2:16 ▶ Grobs 2:13

PvPの優先順位

  • 1〜2位。Hostile Players、次にPlayers Attacking Me。グローバル版では初期の1位が「攻撃した、または照準した対象」で、プレイヤーは2位と3位に入っている。Hostile Playersを最上位に移すのが最低限で、Grobsはそれ以外を変えていない。 ▶ 2:34
  • 3〜8位。すでに攻撃した対象、続いてモンスターとNPCを初期の順で。
  • 9〜10位。プレイヤーの精霊（グローバル版クライアントでは使い魔）は最下位に置く。これはスピリットマスターの精霊のこと。グローバル版では初期状態で4位と6位にあり、モンスターより上なので、PvPでTabが精霊ばかり選んでしまう。

2人の解説者とも、この2つは同じ設定にしている。PvEだけなら、Closest FirstでもTabで最も近い対象を選ぶだけなので問題ない。Front of Cameraは使う価値がある。

Combat Looting and Auto-use

Looting → Obtaining Gear / Obtaining Item

すべて、またはフィルター

装備のグレード（Common、Rareなど）やアイテムの種類（ポーション、シャード、製作素材）ごとに拾わない設定にできる。周回でバッグがいっぱいになるときに便利。

Auto-use → Buff Auto-use Conditions

In Combat

バフスクロールはたいてい自動使用に入れてある。「移動中」を選ぶと動いた瞬間に使われ、「常時」だとずっと使われる。どちらもスクロールの無駄になる。

Auto-use → Life Potion

ON、動画では83%

設定したHPを下回ると自動でポーションを飲む。

▶ 2:47

近接クラスは注意：近接クラスは対象がいなくても武器を振れるので、街で左クリックを1回しただけで戦闘扱いになり、スクロールが使われる。レンジャーは自動攻撃に対象が必要なので、これは起きない。

Key Settings：割り当てておきたいキー

キーは解説者本人のもの。自分の好きなキーでいい。大事なのは、これらの操作にキーが割り当たっていること。

General → Separate Defiance Hotkey + Set Defiance Hotkey

ON、キーは`（1の左）。初期値：OFF

初期状態ではDefiance（拘束解除）がジャンプ・滑空と同じSpaceに入っている。拘束中にSpaceを連打すると滑空が始まり、次の行動が台無しになる。ボスのギミックやPvPの戦闘を落とす原因になる。

General → Fly Up, Fly Down

Fly Upはマウスのサイドボタン。初期値：Ctrl+RとCtrl+F

カメラを傾けずにまっすぐ上昇・下降できるので、PvPでもカメラが対象から外れない。どちらも常に使うのに、Ctrl+Rを押したい人はいない。最初のログインで割り当て直して慣れておこう。

General → Macro

右クリック。初期値：キーなし

キーがないとマクロはまったく動かない。戦闘中ずっと押しっぱなしにするので、最も押しやすいボタンに置く。ほとんどのプレイヤーは右クリック。

General → Target Hostile Players

Caps（Whelps）。例：マウスの中ボタン（Grobs）

敵プレイヤーだけを対象にする。アビスではTabがモンスターを選びがちだが、このキーなら選ばない。Grobs本人は使っていない。Priority Rankingで足りるため。

General → Switch Control Mode

/

AION 2モードとAION 1モードをその場で切り替える。

General → Combat Analysis

Ctrl+X

内蔵のダメージメーターを開く。

Menu → Display Cursor

Alt（押している間）

AION 2モードで、押している間カーソルが出てUIをクリックできる。

Quickslot

1スロットにつき2キー

ホットバーの各スロットにメインと2つ目のキーを割り当てられる。

Marker

テンキーでマーカーを付け、Ctrl+1でマーカー1を選択

ボイスチャットを使うパーティーPvP向け：リーダーが対象にマーカーを付け、全員がキー1つでそれを選ぶ。

▶ 3:30 ▶ Grobs 5:52

会話をより速く飛ばす

Key Settingsの各操作にはキー欄が2つある。Interact（初期値はF）の隣にZなどの2つ目のキーを割り当てて、2つを交互に連打すると、Fを指1本で押すときの約2倍の速さでクエストの会話が進む。45までは会話がとても多いので、積み重なると大きい。

Info Display：画面に表示するもの

Combat → Aggro Range Display

ON

モンスターを選ぶと青い円が見える。その中に入ると襲ってくる。

Combat → Display Boss Orientation Indicator

ALL

ボスの周りに弧が出る。青い部分が正面、黄色い部分が背面。背後に立つ助けになる。

Combat → Display Skill Range

ON

スキルの射程が表示される。

Common → Performance → Display Network Status

ON

画面の隅にpingの表示が出る。

Common → Pets → Display Other Players' Pets

OFF

自分のペットは残り、他人のペットは消える。処理が重くなるだけなので。

Common → Nameplate

好みで

他のプレイヤー、その精霊、モンスターのネームプレートを隠すと画面がすっきりする。自分のネームプレートは隠せない。

Floater → Combat Floater Display

ON、UIは小さめ

飛び出すダメージと回復の数字。すべて、または個別（被ダメージ、被回復、対象へのダメージなど）にオフにできるが、攻撃の手応えがなくなる。Grobsは表示したまま、UI Proportionで小さくしている。Graphicsを参照。

▶ 5:45 ▶ Grobs 3:24

Graphics Optimize：FPSと大規模PvP

画質のプリセットはPCの性能次第。ここにあるのは、環境に関係なく効く設定。

UI Proportion

Small（初期値：Medium）

UIとダメージ数字がまとめて縮小される。UIを小さくすると数字も小さくなり、戦闘を覆い隠さなくなる。

Effect Quality

Very Low

FPSへの影響が何より大きく（Whelpsは他の項目をVery Highのままにしている）、パーティクルも大幅に減る。長時間のプレイでも目がずっと楽。

Upscaler

DLSS

NVIDIA製のグラフィックスカードの場合。

Frame Generator

PvEではOFF、大規模PvPではON

フレーム生成は入力遅延を増やし、入力遅延はそのまま火力の損失になる。大規模戦では滑らかさのほうが重要。

Player Particle Effect Display

Self Only（Grobs）。Self and Party（Whelps）

Self Onlyにすると、味方も含めて自分以外のスキルエフェクトが消える。画面がすっきりし、FPSも明らかに上がる。たまに見えなくて困ることはあるが、それだけの価値はある。

NVIDIA Reflex

BOOST

入力遅延が小さくなる。

Volumetric Light Scattering, Volumetric Fog

動画ではOFF

解説者の画面での設定。これらについては触れていない。

[Abyss] Display as Tier Icon

ON

アビスでの敵のネームプレートが小さなランクアイコンになり、画面上の表示がかなり減る。

Identical Player Appearance

ON

他のプレイヤーがすべて同じ簡素な見た目になる。すぐに反映される。ゲームは攻城戦のような大規模戦に最適化されておらず、これがないとどんなPCでもほぼ遊べない。

▶ 6:50 ▶ Grobs 3:53

その隣に[Domination] Display as Tier Iconがある。Domination用の同じスイッチで、動画ではOFF。

Graphics Camera / Direction

World Map Transition Animation

OFF

そうしないとマップを開くたびにアニメーションが流れ、目が回る。

Teleport Effect Color

Dark（初期値：Bright）

Brightだと、テレポートのたびに目の前が真っ白になる。

Camera Perspective

Default、または肩越し

後者はキャラクターが中央より少し左に寄る。

Camera Shake Effect During Combat

OFF

2人の解説者ともオフにしている。好みの問題で、揺れが好きな人もいる。

Display Weapon Outside of Combat

ON（初期値：OFF）

見た目だけの設定。戦闘外でも武器が消えずに表示される。

Display Equipped Title Effects on Nameplate

好みで

特別な称号が名前の周りに付ける枠。OFFにすると消える。「自分のネームプレートのみ」という選択肢もある。

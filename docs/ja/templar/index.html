概要

テンプラーはAION 2のメインタンクで、それでいて火力もしっかり出る。ビルド全体を支えるのは、できるだけ早く20まで上げる3つのスキルの「三位一体」：審判、懲罰、連続乱打。これをとにかく回せるだけ回す。テンプラーの限界を決めるのは生存力ではなく火力だ。

ビルドを一言で

盾スキルが審判を発動させる。審判ラインをサイドボタンで連打し、マクロを押しっぱなしにして連続乱打とその発動スキルを回す。懲罰は再使用時間が明けるたびにチャージして撃ち、大きな攻撃はガードしてパーティーに激昂を維持する。

このガイドはSolAshurのグローバル版ローンチ向けテンプラービルド（solashur.com、9月27日）と、その解説動画（9月29日）に基づく。9月30日に動画のフレームと照らし合わせて再確認した。

パッチ シーズン1. ビルドはグローバルサーバーのガイドと照らして確認済み：スティグマ4つ、上限20。

概要

PvPでも三位一体と審判のループは変わらない。変わるのはスティグマだ。処刑の剣はどの決闘でも優位をもたらし、殲滅は20で範囲転倒スキルになる。

近接はカイトされる。相手に届かなければ強い武器も意味が薄いので、接近スキルと破滅のシールドを軸に立ち回ろう。

KR/TWのPvP専用装備セットはグローバル版での実装が未確認なので、PvEタブのPvX装備で進める想定だ。PvP装備が出た場合は、まずPvPスティグマを上げ、そのあとでPvP武器や防具に投資する。

パッチ シーズン1. ビルドはグローバルサーバーのガイドと照らして確認済み：スティグマ4つ、上限20。

グローバル版シーズン1：変更点

グローバル版サーバーは2026年10月5日にオープンする（ファウンダー先行アクセスは9月30日から）。テンプラーにとっての意味は次のとおり。

  • Lv45でスティグマは4つ。SolAshurの台湾版の構成は6つだったが、グローバル版ではプロファイルごとに2つ外している（「スティグマ」に記載）。
  • ローンチ前にスキルプリセットを3つ作る：PvX、PvP、PvE。コンテンツの切り替えがワンクリックで済む。
  • Skill Point Shardは早めに集める：三位一体が20に届く速さはこれで決まる。
  • レギオンに入る：ソロでのアビス周回は効率が悪い。
  • ローンチ時にスティグマ名を確認しよう。グローバル版クライアントでは名前が変わっているものがあるかもしれない。

パッシブ

#パッシブ理由
1激昂ガードするたびに自分とパーティーのPvEダメージ増幅が上がる。パーティーがテンプラーを欲しがる理由だ。
2断罪の加護攻撃が当たるたびにクリティカルと追加ダメージの発動。鐘のアルカナで狙える。
3侮辱の咆哮ヘイトに加え、正面からの攻撃で攻撃力が上がる。
4鉄壁防御防御力と鉄壁。鉄壁型ステータスビルドの核になる。SolAshurのキャラクター（+6レベル）では防御力+37%、鉄壁+16%。

装備の進め方

初日から始めるなら、ルートは次のとおり。

  1. 聖霊セット：アビス下層（1体倒すごとにアビス ポイント、ペット、ゴールドがドロップし、ボスも出現する）か、オープンワールドのどこでも集められる。戦闘力1,600前後が目安。
  2. 最初のダンジョン帯は飛ばす：ウルググ峡谷でアウルラムスのロングソード（アイテムレベル76、攻撃力308–385、取得時に刻印）、バクロンの空中島でバクロンのガーダー（アイテムレベル76）とバクロンの防具を狙う。炎の神殿に挑めるようになるまでバクロン装備を強化し続ける。
  3. 超越で炎の神殿（怒りのクロメデのソード：アイテムレベル84、攻撃力340–425、射程延長）と獰猛な角岩窟（Nuakum防具）に備える。周回はNuakumの方が安全：ほぼ全部位が更新になる一方、武器箱からは他クラスの武器が出ることがある。
  4. 最終目標：PvEなら白龍王の剣、次に盾、次にアクセサリーで、防具はNuakum（白龍防具一式はPvE耐性が増えるだけで、重課金者の領域）。大半のプレイヤー向けのPvX構成は、怒りのクロメデの剣、白龍の盾、Nuakum防具、白龍のアクセサリー。

翼：序盤はDark Veil（追加攻撃力、ダメージ増幅）、終盤はTalisra：攻撃力60、防御力400、命中35、再使用時間減少4%。再使用時間減少はできるだけ早く積もう。盾スキルのクールタイムが短いほど審判の発動が増える。ほかの翼もすべて集めておく。「所持」効果と飛行力がアビス周回の助けになる。

AION 2には別々のツールが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと使用可能なスキルのうち最も優先度の高いものが発動し、AION 2では一番下のスロットが最優先になる。カードは各ラインをゲーム内と同じく上から下の順に表示している。
  • ゲーム内マクロ：キーを押している間、ホットバーラインを順番に押し、モーションの後隙をキャンセルする。再使用待ちのスキルは飛ばされる。

まとめ

  • スキル：同じ三位一体を20に。加えて範囲転倒のために殲滅も20。

レベリング中の戦い方

  • 雑魚の群れ：捕獲で1体引き寄せる（倒すと再使用時間が初期化）→ 庇護の一撃 → 猛烈な一撃 + 連続乱打マクロを押しっぱなし。
  • エリート：チャージした懲罰 → シールド強打（気絶）→ 審判 → 殲滅。
  • MP：猛烈な一撃でMPが回復し、連続乱打で消費する。交互に使えばMPは切れない。
  • HPが減ったら：庇護の一撃で回復しつつ被ダメージを減らす。ガードするたびに庇護のシールドでHPが回復する。

  1. 4 シールド強打
  2. 3 審判
  3. 2 衰弱の猛打
  4. 1 破滅のシールド

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

2ライン2
  1. 2 連続乱打
  2. 1 庇護の一撃

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

ゲーム内マクロ：ライン1 → ライン2、それぞれディレイ10ms。左クリックの基本攻撃猛烈な一撃とマクロキーを同時に押し続ける。

スキルが12–16になり、特化で再使用時間が変わったら、PvEタブの完全版の構成に切り替えよう。

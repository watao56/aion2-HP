概要

ソーサラーは火と氷を操る遠距離の紙装甲アタッカー。ダメージ源は火で、火の印で対象に印を付け、炎爆発でそれを消費して大ダメージを出す。氷は鈍化・束縛・氷結で敵を近づけない役割。ダメージボーナスの半分はMP次第で、MPが50%以上ならクリティカルが上がり、25%以上ならダメージが20%増える。

ビルドをひと言で

マクロを1つ押しっぱなしにして元素強化と集中の祈願を維持しつつ、炎の矢と火・氷のラインを交互に撃ってMPを半分以上に保つ。地獄の火炎だけは手動で撃つ。

  • ターゲットモードで遊ぶ。ターゲットを固定していれば、通常攻撃の炎の矢がスキルを使うたびに自動で再開し、MPも回復する。アクションモードではスキルのたびに止まるので、そのつどクリックし直す必要がある。
  • 段階は2つ。Lv45になった最初の数日はスキルが8〜10で、特化は1つずつ。カードに書いたMPとスピード系の特化を取る。カードのレベルとハイライトされた2つの特化は後の目標（16）で、EUTOPIAのグローバル版構成と韓国のガイドに基づく。

序盤の構成とマクロはaLuckyROのソーサラー初心者ガイド（動画、9月15日、台湾クライアント）と10月2日のグローバル版向けアップデートに、スキルの優先度とLv16の特化はEUTOPIAのグローバル版ビルド（Lv45、アイテムレベル1,260、10月3日）に従う。EUTOPIAは自分のパーティーでダメージ1位を取っているプレイヤー。スキル名とデータはグローバル版クライアントのもの。

パッチ シーズン1. ビルドはグローバルサーバーのガイドと照らして確認済み：スティグマ4つ、上限20。

グローバル版シーズン1：変更点

グローバル版サーバーは2026年10月5日オープン（ファウンダー先行アクセスは9月30日から）。ソーサラーにとっての影響は次のとおり。

  • スティグマ枠は4つ、上限は20。台湾と韓国は6枠。ここで残した4つは、どちらのソースも最初に上げているもの。
  • スキルは20ではなく16。スキルを16より上に押し上げるのはアルカナと指輪で、どちらも入手に時間がかかる。
  • 序盤はMPが苦しい。MPは約3,000で再使用時間減少もない。序盤の特化はダメージではなく、MPとスキル速度のために取る。
  • PvP：全員が同じ限られた装備から始まり、メタはまだ固まっていない。

パッシブ

パッシブ理由
炎のローブ命中、PvEダメージ増幅、強打。最初に最大まで上げるパッシブ。
火の印炎爆発に必要な火の印を付与し、対象を燃やす。最大まで上げる。
大地のローブ最大MPと、MPが50%以上のときのクリティカル。最大まで上げる。
強化の恩恵MPが25%以上のときPvEダメージ増幅20%、さらに追加ダメージ。
生気蒸発対象のHPが70%を超えている間は追加ダメージ。戦闘が短い序盤に強い。
冷気召喚鈍化状態の対象に追加ダメージ。氷鎖で鈍化を維持できる。
冷気のローブ防御力と、攻撃してきた相手への鈍化。レイド向け。

大地のローブと強化の恩恵はMPが減ると効果が切れる。MP10〜20%で戦い続けるのは絶対に避けよう。

装備とステータス

  • 魔石：攻撃力、クリティカル、命中。
  • ローテーションでMPが枯れなくなるまでは、最大MPとMP自然回復を意識する。
  • どの段階の装備を目指すかは、グローバル版のローンチまではまだ決まっていない。

ディーヴァニオン ボード

ディーヴァニオンでスキルが10から14まで上がり、ステータスも伸びる。青いノード1つで、そのスキルが+1レベルになる。

  • 優先度：オレンジの戦闘速度と再使用時間減少、次に攻撃力とダメージ増幅、その次にクリティカル ダメージ増幅。その後は地獄の火炎、炎の槍、極寒の風、炎爆発、集中の祈願の青ノードと、緑の大地のローブ。
  • 多段ヒットと防御系のオレンジノードは取らない。ソーサラーが欲しいのは素のダメージ。命中は後から拾えばいい。
  • 優先度：氷結、冬の束縛、炎の槍の青ノード。
  • グローバル版にアリエルはない：ボードは5枚で、Lv45のアスフェルはPvPダメージ増幅と耐性しかくれない。PvEでは最初の4枚を埋める。
  • アスフェル（Lv45）はすべてPvPダメージ増幅と耐性。取ろう。

マクロとローテーション

?The macro key is not bound by default: bind it in Settings → Key Settings → General → Macro. Bind it to RMB — then you hold it together with the basic attack on LMB.

AION 2には別々の仕組みが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと、使えるスキルのうち優先度が最も高いものが発動する。AION 2では一番下のスロットが最優先。カードでは各ラインをゲーム内と同じく上から下へ並べている。
  • ゲーム内マクロ：キーを押している間、ホットバーのボタンを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

1. ホットバーライン

4バフライン
  1. 3 遅延爆発
  2. 2 極寒の風
  3. 1 元素強化

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

元素強化は使えるようになり次第発動。その次に束縛の領域と、ダメージ+15%のデバフ。

5集中ライン
  1. 3 火の障壁
  2. 2 冷気暴風
  3. 1 集中の祈願

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

まず2つ目のバフ、次に対象の足元へ2つの領域。

1火ライン
  1. 2 炎の槍
  2. 1 炎爆発

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

対象に火の印があれば炎爆発、炎の槍は再使用時間5秒ごとに。

T氷ライン
  1. 2 氷鎖
  2. 1 冬の束縛

ゲーム内の並び順で、上から下へ。1が最優先で、最下段のスロット。

ダメージバフのために冬の束縛。氷鎖を残しているなら残りの時間を埋める。外しているならこのラインは冬の束縛だけ。

炎の矢は単独でR、地獄の火炎は2、火炎乱射は3に置く。

2. ゲーム内マクロ

マクロキーはSettings → Key settings → Gameplay → Macroで設定する。全ステップを同じディレイにする。

  1. 1バフライン4
  2. 2集中ライン5
  3. 3炎の矢R
  4. 4火ライン1
  5. 5炎の矢R
  6. 6氷ラインT
  7. 7火炎乱射3
  • ディレイ：Pingが50未満なら10ms、Pingが80〜100以上なら40〜50ms。
  • 確認方法：マクロ実行中に自キャラを見る。後ろに残像（「影」）が出ていればモーションがキャンセルできていて、ディレイは適切。
  • 炎の矢が2回ある理由：重いスキルの合間にMPを補給して50%以上を保ち、MP条件のパッシブを2つとも有効にしておくため。

ステップはaLuckyROのマクロ画面（9月15日、台湾クライアント）から取り、EUTOPIAのグローバル版構成に合わせて氷結と氷結爆発を外した。最後のステップを火炎乱射にしたのはaLuckyROの説明による（グロッキー状態のボスには勝手に発動する）。

3. 実際に押すもの

  • 押しっぱなしマクロキー。ほかには何も押さない。
  • 手動地獄の火炎：止まってフルチャージし、マクロに戻る。
  • MP不足それでもMPが減るなら、マクロを離して炎の矢を何発か撃ってから再開する。

4. 後半：手動でバースト

装備に再使用時間減少が付いてきたら、韓国のプレイヤーはバフをマクロから外し、手動でバーストのタイミングを作っている。

  1. タンクが釣る直前に遅延爆発。
  2. 元素強化と集中の祈願。
  3. ボスの足元に火の障壁 + 冷気暴風。
  4. 極寒の風、続けて冬の束縛でダメージ増幅+20%。
  5. 地獄の火炎を3段階までチャージし、その後マクロ。

まとめ

  • 最初の数日：スキルは8〜10でMPとスピード系の特化。バフ入りのマクロ1つ。ターゲットモード。
  • 後半：地獄の火炎、炎の槍、極寒の風、炎爆発、集中の祈願、冬の束縛、炎の矢を16。氷鎖は12かホットバーから外す。
  • スティグマ：元素強化20、冷気暴風10、火の障壁10、遅延爆発10。
  • MP：50%以上を保つ。快適さのためではなく、それ自体がダメージになる。

レベリング中の戦い方

  • 敵の群れ：極寒の風（束縛 + 引き寄せ）→ 地獄の火炎 → 倒れるまで氷鎖。
  • エリート：炎の矢で火の印 → 炎爆発 → 炎の槍。氷鎖の鈍化でカイトしながら戦う。
  • MP：ターゲットモードで通常攻撃を回し続け、炎の矢を挟む。
  • HPが減ったら：鋼鉄のバリアを張って距離を取る。ソーサラーに回復スキルはない。

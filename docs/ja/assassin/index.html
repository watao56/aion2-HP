概要

アサシンはバフ頼みのダガー系バーストクラス。攻撃を当てると対象に紋様が刻まれ、紋様爆発でそれを一気に爆発させる。心臓突きはクリティカルで発動し、次のクリティカルで自分の再使用時間がリセットされる。最大のダメージボーナスは対象の背後から当てることで得られるため、立ち位置の重要度はどのクラスよりも高い。

ビルドを一言でまとめると

ボスの背後に立ち、迅速斬りを常に挟み、紋様爆発は使えるようになった瞬間に、心臓突きはクリティカルのたびに押す。そして心臓突きの再使用時間が完全になくなる幻影分身の20秒間に、持てる火力をすべて注ぎ込む。

シーズン1で覚悟しておくこと

  • バーストの後に空白がある。KR/TWでは幻影分身のLv25段階のおかげで、上手いプレイヤーは常時維持できる。グローバル版は20止まりなので、再使用時間1分30秒に対してバーストは約20秒。その合間はつなぎ技で戦い、心臓突きはクリティカルの運任せになる。
  • バフの周期が揃わない。迅速の契約と猛獣の牙は1分、幻影分身は1分30秒で戻ってくる。待つか押すかを常に判断し続けることになる。
  • 背後を取れている時間がそのまま火力。木人相手なら100%だが、実戦では60〜80%と見ておこう。正面から当てた攻撃はすべて背後強打のボーナスを失う。
  • 打たれ弱い。ガードがなく防御力も低い。グラディエーターなら耐えられるミスでも死ぬ。

Arthars の評価：楽しくて腕前が問われるクラスだが、グラディエーターやソーサラーと同じかそれ以下のダメージを出すのに何倍もの手間がかかる。数字目当てではなく、プレイスタイルが好きで選ぶクラスだ。

PvEモードは、Arthars Gaming のグローバル版ローンチ向けアサシン動画(9月30日、台湾サーバーで収録)を1フレームずつ読み取ってまとめた。動画に字幕がないため、テキストは音声認識で音声から起こし、名前と数値はすべて画面と照合している。レベリングは TitanTheF のシートに基づく。

パッチ シーズン1. ビルドはグローバルサーバーのガイドと照らして確認済み：スティグマ4つ、上限20。

グローバル版シーズン1：変更点

グローバル版サーバーは2026年10月5日にオープンする(ファウンダー先行アクセスは9月30日から)。アサシンにとっての影響は次のとおり。

  • スティグマ枠は4つ、上限は20。4つともダメージ用に使う：幻影分身、迅速の契約、猛獣の牙、トリニエルの刃。
  • 幻影分身の常時維持はできない。背後クリティカルで再使用時間が短縮される段階はLv25で、グローバル版にはない。
  • 序盤は再使用時間減少が少ない。暴風乱舞を16まで上げ、トリニエルの刃をダメージ目的ではなく再使用時間短縮の道具として使うのはこのため。
  • 戦闘が長引く。台湾サーバーで30秒で倒れるボスも数分かかるはず。バーストのタイミングもその合間も何度も経験することになる。
  • PvP：全員が同じ限られた装備からのスタートで、メタはまだ固まっていない。

アクティブスキルとパッシブはグローバル版とKR/TWのデータで同一。スティグマはLv25段階がなくなる。

パッシブ

パッシブのほとんどはレベリング中にスキルポイントで最大になる。足りないのは装備のオプション枠で、このクラスは4つのパッシブを載せたいのに入るのは2〜3つだけ。

パッシブ装備での優先度理由
背後強打1後方攻撃とPvEダメージ増幅。最強のパッシブで、正面からでもダメージが伸びる。
隙突き2クリティカルと、戦闘中ほぼ常時かかっている攻撃力バフ。幻影分身で効果が倍増する。
強襲姿勢2クリティカル ダメージ増幅。迅速の契約で効果が倍増する。
覚悟3HPの減った対象への追加ダメージ。aLuckyRO はこれを最重要のひとつに数えている：どのボスも戦闘の終盤はこの状態で過ごすからだ。
衝撃的中4強打。Lv10でもわずか3.3%で、PvEではほぼ無意味(aLuckyRO)。PvP用に取っておき、PvE装備では覚悟を優先する。
奇襲姿勢、六感極大化ポイントのみスキルポイントで最大になる。装備のオプション枠を使う価値はない。
毒塗り、防御亀裂不要毒はダメージ全体の1%未満、防御亀裂はPvP用パッシブ。蘇生の契約はポイントが余ったときだけ。

装備とステータス

  • 指輪：アクティブスキルを載せられる唯一の部位。心臓突き、迅速斬り、紋様爆発、奇襲。これで主要スキルが14から16になる。
  • 武器とガーダー：スキルは絶対に載せない。ここのダメージ系オプションはスキル1レベル分より価値がある。
  • その他の部位：背後強打が最優先。次の3つのパッシブはどれでもいい。シーズン1で完璧なセットを追い求めないこと。グローバル版の装備はオプションが1行少なく、そこに Might、Precision、戦闘速度も付く。
  • クリティカルは他のクラスより重要：心臓突きはクリティカルでしかリセットされない。
  • 魔石：攻撃力、クリティカル、命中。

アルカナ

シーズン1のカードは5枚、セットは2種類。アサシンは鏡で Illusion(再使用時間)を必ず取る唯一のクラスなので、太初の活力4枚が自然なセットになる。

カードステータスセット狙うスキル
聖杯Time(戦闘速度)太初の活力主要3スキルのうち、まだ20に届いていないもの
羊皮紙Life太初の活力迅速斬り、心臓突き、紋様爆発の3つすべて
コンパスFreedom(命中)太初の活力暴風乱舞、奇襲、猛獣の咆哮を16にするため
鏡Illusion(再使用時間)太初の活力背後強打、隙突き；衝撃的中
鐘Destruction(攻撃力)魔力鎧強襲姿勢

厳選の本番は羊皮紙。20にしたい3スキルがすべてこの1枚に載っているのに、シーズン1のカードは4行のうち2行しか選べない。カードのレベルを上げるとランダムに+1が4回付く。1つに+4が偏るより、均等に散る(それぞれ+2)ほうがありがたい：足りない+2は聖杯で補える。うまくいかなければ、心臓突きと紋様爆発を20にして迅速斬りは16のままにする。

コンパスと鐘は気楽でいい：どちらも20にする必要のあるスキルはない。これらのカードはどれも、シーズン2で新カードが来たら入れ替わる。

ディーヴァニオン ボード

ディーヴァニオンはスキルを10から14に引き上げ、ステータスも伸ばす。青ノード1つで、そのスキルが+1レベルになる。

  • 優先順位：心臓突き、紋様爆発、迅速斬りの青ノード、次に奇襲と暴風乱舞。その後にオレンジノード。
  • クリティカル ダメージは早めに：アサシンならバイゼルのオレンジノード(クリティカル ダメージ増幅)が最初から元を取れる。多くのクラスと違い、初日からクリティカルが出るからだ(aLuckyRO)。
  • 優先順位：闇討、閃光斬り、衝撃解除の青ノード。
  • グローバル版にアリエルはない：ボードは5枚で、Lv45のアスフェルはPvPダメージ増幅と耐性しかくれない。PvEでは最初の4枚を仕上げよう。
  • アスフェル(Lv45)はすべてPvPダメージ増幅と耐性。取ろう。トリニエルも早めに取る。

スティグマ

マクロとローテーション

AION 2には別々の仕組みが2つある。

  • ホットバーライン：1つのホットバーボタンに複数のスキルを重ねたもの。押すと、使える中で優先度が最も高いスキルが発動する。AION 2では一番下のスロットが最優先。カードはゲーム内と同じく各ラインを上から下へ並べている。
  • ゲーム内マクロ：キーを押している間、ホットバーのボタンを順番に押し、モーションの後隙をキャンセルする。再使用時間中のスキルは飛ばされる。

2ステップ、それぞれ10ms。押しっぱなしにできるキーに割り当てる。

  1. 1ダメージライン10ms
  2. 2迅速斬り10ms

動画ではホットバーは映っているが、マクロ画面は映っていない。このマクロは Arthars のチャンターガイドの設定(メインライン、次に基本攻撃)にならったもの。ラインとキーは彼のホットバーから読み取った。

3. 実際に押すもの

  • 押しっぱなしマクロキー。さらに迅速斬りを自分で連打する。1ヒットごとに紋様爆発の再使用時間が短くなる。
  • バースト幻影分身+迅速の契約+猛獣の牙を同時に使い、すぐにトリニエルの刃でそれらの再使用時間を削る。その後の20秒間は心臓突きを撃ち続ける。
  • バーストの合間迅速の契約と猛獣の牙は幻影分身より先に戻ってくる。次の分身まで温存する(バーストが大きくなる)か、クールタイムごとに使う(ダメージが安定する)か。決まった答えはないが、短い戦闘なら温存しよう。
  • グロッキーグロッキー中のボスに暴風乱舞、合間に迅速斬りを挟む。すべての再使用時間が秒単位で縮む。
  • 位置取り闇討、閃光斬り、侵入はどれも対象の背後に回り込める。ダメージ用ではなく、背後に居続けるために使う。

Arthars の木人でのテストにおけるダメージ内訳：心臓突きが約30%、紋様爆発が約25%、それ以外はどれも6%以下。

まとめ

  • スキル：心臓突き、紋様爆発、迅速斬りは16 → 20。奇襲と暴風乱舞は16。残りは12。
  • スティグマ：幻影分身20、迅速の契約15 → 20、猛獣の牙15、トリニエルの刃10。
  • 装備に載せるパッシブ：背後強打、次に隙突き、強襲姿勢、衝撃的中。
  • 立ち回り：ボスの背後に立ち、幻影分身の間にバースト、バフの直後にトリニエルの刃。

レベリング中の戦い方

  • 集団：猛獣の牙(紋様5個)→紋様爆発→旋風斬り。暗器投擲は敵を倒すとリセットされるので、次の釣りに使える。
  • 強敵：背後を取る→奇襲→猛獣の咆哮で紋様を重ねる→紋様爆発→クリティカルが出たら心臓突き。
  • MP：迅速斬りはMPを回復する。左クリックに置いておこう。
  • HPが減ったら：影落下でHPを吸収。追い込まれたら衝撃解除で回復。

レベリング用マクロ

レベリング中、心臓突きが16になる前は、TitanTheF のもっとシンプルな設定がLv1から使える：紋様ラインをゲーム内マクロにしてホイールクリックに、迅速斬りを左クリック、心臓突きをQに置く。雑魚狩りでは暗器投擲(2)と右クリックを使う。Lv1〜45の序盤ビルド：迅速斬り、猛獣の咆哮、紋様爆発、心臓突きを12、それ以外は8。

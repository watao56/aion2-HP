Что есть в каждом гайде

PvE / PvP / Прокачка

Один переключатель меняет всю страницу: чистый PvE-билд, чистый PvP-билд или чек-лист прокачки.

Данные глобального клиента

Названия скиллов, специализации и уровни стигм взяты из глобальной базы, а не из корейского клиента.

Отслеживание прогресса

Отмечай шаги прокачки по ходу игры — прогресс сохраняется в браузере отдельно для каждого класса.
